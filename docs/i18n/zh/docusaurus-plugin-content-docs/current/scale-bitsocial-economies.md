# 扩大 Bitsocial 经济体系

第 4 阶段的目标，是让生态大到没有任何单一公司、RPC、托管服务商或客户端能成为新的平台所有者。

Bitsocial Forge 可以建成第一个公共 RPC 和第一批主要服务，但那不应该是终态。如果许多企业、团队、匿名运营者、社区组织和独立开发者都能在 Bitsocial 之上构建有用的基础设施，网络会更健康。

## 需要扩大的是什么

生态需要的不只是应用：

- 互相竞争的公共 RPC
- 媒体托管服务
- 发现与索引服务
- 审核服务
- 信息流算法提供方
- 个人资料节点托管
- 分析与可观测性
- 开发者工具
- 资助与融资渠道

每一项服务都应该是可替换的。有用的提供方可以做得很成功，但用户和应用始终要有别处可去。

## 资助本身就是去中心化

资金应该推动网络走向更多独立运营者，而不是走向一个永久的中心枢纽。

这意味着资助那些构建客户端、基础设施、审核工具、索引工具、移动端体验、媒体服务和竞争性 RPC 的开发者，也意味着给企业、社区团体、匿名运营者和独立开发者留出空间，让他们能在网络内部找到可持续的生意。

## 经济体系为什么重要

社交基础设施的维护成本很高。如果只有一个组织为 RPC、托管、发现和开发买单，那么即使协议是点对点的，网络依然脆弱。

更稳固的版本，是围绕协议形成一个服务市场：

- 客户端争夺用户
- RPC 在可靠性和信任模型上竞争
- 媒体托管方在价格和政策上竞争
- 发现服务在相关性上竞争
- 开发者争取资助、收入和声誉

Bitsocial 经济体系应当让有价值的工作能在许多独立参与者之间获得资金，从而使协议更难被任何一方掌控。
