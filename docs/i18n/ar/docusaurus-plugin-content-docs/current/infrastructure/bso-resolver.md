# محلّل BSO

يترجم محلّل BSO أسماء نطاقات `.bso` إلى المفاتيح العامة المقابلة لها بقراءة سجلات TXT الخاصة بـ Bitsocial. وهو حزمة التحليل التي تستخدمها أدوات Bitsocial عندما يحتاج اسم `.bso` الموجّه للمستخدم إلى التحوّل إلى مادة المفاتيح التي تفهمها حزمة النظير إلى النظير.

- **الشيفرة المصدرية وملف README الحالي:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **حزمة npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## التثبيت

```bash
npm install @bitsocial/bso-resolver
```

## أين يقع في المنظومة

أسماء Bitsocial مقصودة لتكون مداخل مقروءة للبشر إلى المجتمعات والمؤلفين. ويُبقي المحلّل طبقة التسمية هذه منفصلة عن شيفرة التطبيق، فيستطيع العملاء أن يسألوا أولًا عمّا إذا كان الاسم مدعومًا ثم يحلّوه عبر نقطة الدخول المخصصة لبيئة التشغيل في الحزمة.

استخدمه عند بناء تكامل مع عميل أو أداة سطر أوامر أو خدمة تدرك Bitsocial وتحتاج إلى قبول أسماء `.bso` بدل الاقتصار على المفاتيح العامة الخام.
