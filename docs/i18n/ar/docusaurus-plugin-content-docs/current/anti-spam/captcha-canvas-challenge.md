# تحدي كابتشا Canvas

تحدي كابتشا Canvas حزمة كابتشا مصوّرة مستقلة لمجتمعات Bitsocial. ترسم نصًا عشوائيًا على لوحة رسم، وتتيح للمجتمع أن يطلب من المؤلفين حلّ الصورة قبل قبول أي منشور.

- **الشيفرة المصدرية وملف README الحالي:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **حزمة npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## التثبيت

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## أين تناسب

تحديات الكابتشا مفيدة حين يريد المجتمع بوابة تفاعلية بسيطة لمقاومة البريد العشوائي في الحالات منخفضة المخاطر. وهذه الحزمة محدودة النطاق عن قصد: فهي توفّر تنفيذ التحدي فقط، بينما يقرر المجتمع أو عقدة Bitsocial متى وكيف يُعرض.

وللحصول على حماية أقوى، اجمعها مع أنظمة إشراف أوسع أو أنظمة لتقييم المخاطر، بدل التعامل مع الكابتشا كاستراتيجية كاملة لمكافحة البريد العشوائي.

## مرجع الحزمة الحالي

هذه الصفحة نظرة عامة عن قصد، وليست نسخة مطابقة من دليل الإعداد. فملف README الخاص بالحزمة هو المرجع الموثوق لأسماء التحديات الحالية، وأمثلة التسجيل، وأمثلة CLI، والخيارات المدعومة، والمتطلبات، وملاحظات الأمان:

- [ملف README الخاص بتحدي كابتشا Canvas](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)

فضّل الرجوع إلى ملف README الأصلي عند إعداد مجتمع حي، لأن خيارات الحزمة ومسارات التثبيت تُصدَر مع تلك الحزمة لا مع هذا الموقع.
