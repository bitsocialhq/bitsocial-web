# سياسة اللغة الافتراضية في i18n

يحدد الزوار المجهولون اللغة وفق الترتيب التالي:

1. معامل الاستعلام `?lang=`
2. اختيار اللغة المحفوظ من محدِّد اللغة (في `localStorage` داخل المتصفح، ويُنسَخ إلى ملف تعريف الارتباط `i18nextLng` لأجل العرض على الخادم SSR)
3. لغة المتصفح أو الجهاز عندما تكون ضمن اللغات المدعومة لدينا
4. العودة إلى `en`

لا يُستخدم البلد أو المنطقة لتجاوز لغة متصفح أو جهاز مدعومة. على سبيل المثال، تُحَل `de-DE` إلى الألمانية، وتُحَل `nl-NL` إلى الهولندية، وتُحَل `pt-PT` إلى البرتغالية، لأن عائلات هذه اللغات مدعومة.

وإذا لم تطابق لغة المتصفح أو الجهاز أي لغة مدعومة، فسيحصل الزوار على الإنجليزية الافتراضية.
