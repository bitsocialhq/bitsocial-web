# Bitsocial CLI

`bitsocial-cli` أداة سطر أوامر للتعامل مع الطبقة الخلفية لبروتوكول Bitsocial. وهي تتيح لك تشغيل خدمة daemon محلية للنظير إلى النظير، وإنشاء المجتمعات وضبطها، ونشر المحتوى -- كل ذلك من الطرفية.

وهي مبنية فوق طبقة عميل بروتوكول Bitsocial المشتركة، ويستخدمها كل من [5chan](/apps/5chan/) و[Seedit](/apps/seedit/) لإنشاء المجتمعات وإدارة العقد.

## التثبيت

تتوفر ملفات تنفيذية جاهزة لأنظمة Windows وmacOS وLinux. نزّل أحدث إصدار يناسب نظامك من GitHub:

**[التنزيل من إصدارات GitHub](https://github.com/bitsocialnet/bitsocial-cli/releases)**

بعد التنزيل، اجعل الملف التنفيذي قابلًا للتشغيل (على macOS/Linux):

```bash
chmod +x bitsocial
```

## تشغيل الـ daemon

أشيع استخدام لواجهة سطر الأوامر هو تشغيل عقدة Bitsocial. تبدأ خدمة daemon طبقة الشبكة للنظير إلى النظير وتعرض واجهة برمجية محلية يمكن للعملاء الاتصال بها.

```bash
bitsocial daemon
```

عند أول تشغيل، تطبع خدمة daemon روابط إلى **WebUI**، وهي واجهة رسومية تعمل في المتصفح لإدارة عقدتك ومجتمعاتك وإعداداتك. وهذا مفيد إن كنت تفضّل واجهة رسومية على أوامر الطرفية.

## الإجراءات الأساسية

| الإجراء               | الوصف                                           |
| --------------------- | ----------------------------------------------- |
| تشغيل خدمة daemon     | تشغيل عقدة Bitsocial للنظير إلى النظير          |
| إنشاء مجتمع           | إنشاء مجتمع جديد                                |
| تعديل مجتمع           | تحديث إعدادات المجتمع (العنوان، الوصف، القواعد) |
| سرد المجتمعات المحلية | سرد المجتمعات المستضافة على هذه العقدة          |
| بدء تشغيل مجتمع       | بدء تقديم مجتمع محدد                            |
| إيقاف مجتمع           | إيقاف تقديم مجتمع محدد                          |

شغّل واجهة سطر الأوامر مع `--help` لعرض أسماء الأوامر والرايات التي يوفّرها الإصدار المثبّت لديك:

```bash
bitsocial --help
bitsocial daemon --help
```

## سير العمل المعتاد

سير إعداد شائع لاستضافة مجتمع جديد:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

انطلاقًا من ذلك، استخدم أوامر إدارة المجتمعات في الإصدار المثبّت لديك لإنشاء مجتمع وضبطه وبدء تقديمه. وبمجرد تشغيله، يصبح المجتمع حيًّا على شبكة Bitsocial ومتاحًا من العملاء المتوافقين.
