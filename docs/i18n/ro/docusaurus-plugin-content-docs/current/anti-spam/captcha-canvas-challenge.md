# Captcha Canvas Challenge

Captcha Canvas Challenge este un pachet de captcha cu imagini, de sine stătător, destinat comunităților Bitsocial. Randează text aleatoriu pe un canvas și permite unei comunități să le ceară autorilor să rezolve imaginea înainte ca o publicare să fie acceptată.

- **Cod sursă și README actual:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **Pachet npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## Instalare

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## Unde se potrivește

Provocările de tip captcha sunt utile atunci când o comunitate vrea o barieră interactivă simplă, pentru o rezistență la spam cu miză mică. Acest pachet este intenționat îngust: oferă implementarea provocării, în timp ce comunitatea sau nodul Bitsocial decide când și cum o prezintă.

Pentru o protecție mai puternică, combină-l cu sisteme mai ample de moderare sau de punctare a riscului, în loc să tratezi un captcha ca pe o strategie anti-spam completă.
