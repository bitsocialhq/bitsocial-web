# מדיניות שפת ברירת המחדל ב-i18n

עבור מבקרים אנונימיים השפה נקבעת לפי הסדר הזה:

1. פרמטר השאילתה `?lang=`
2. בחירת השפה השמורה בבורר השפות (`localStorage` בדפדפן, משוקפת לעוגייה `i18nextLng` לצורך רינדור בצד השרת)
3. שפת הדפדפן או המכשיר, כאשר היא אחת מהשפות הנתמכות אצלנו
4. חזרה לברירת המחדל `en`

מדינה או אזור אינם משמשים כדי לעקוף שפת דפדפן או מכשיר נתמכת. לדוגמה, `de-DE` נפתר לגרמנית, `nl-NL` נפתר להולנדית ו-`pt-PT` נפתר לפורטוגזית, מפני שמשפחות השפות האלה נתמכות.

אם אף שפת דפדפן או מכשיר אינה תואמת לשפה נתמכת, המבקרים מקבלים את ברירת המחדל האנגלית.
