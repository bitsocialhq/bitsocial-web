# אתגר קריאה לחוזה EVM

EVM Contract Call Challenge מאמת את מצבו של המחבר על גבי השרשרת לפני שהוא מתיר פרסום. בעלי קהילות יכולים לדרוש שארנק או זהות שנפתרה יעמדו בתנאי לקריאה בלבד מתוך חוזה חכם, למשל החזקת יתרת טוקנים מינימלית, לפני פרסום.

- **קוד מקור ו-README עדכני:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **חבילת npm:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## התקנה

```bash
npm install @bitsocial/evm-contract-challenge
```

## איפה זה משתלב

השתמשו באתגר הזה בקהילות שבהן ההשתתפות צריכה להיות תלויה באות חיצוני מ-EVM: בעלות על טוקן, בעלות על NFT, ציוני הוכחת אנושיות, חברות בגוף ממשל, או כל תנאי אחר שניתן לקרוא מתוך חוזה.

מנקודת מבטו של המחבר האתגר אוטומטי לאחר ההגדרה. הוא בודק מקורות ארנק או זהות כשירים, קורא למתודה שהוגדרה בחוזה, ומשווה את הערך המוחזר לתנאי של הקהילה.

## הפניה לחבילה העדכנית

הדף הזה הוא סקירה בכוונה, ולא שכפול של מדריך תצורה. ה-README של החבילה הוא מקור האמת לשמות האתגרים, לדוגמאות של Bitsocial CLI, לרישום ב-pkc-js, לברירות המחדל של האפשרויות, לדוגמאות ABI, להתנהגות ה-RPC ולמקורות הארנק הנתמכים:

- [README של EVM Contract Challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)

העדיפו את ה-README במקור כשאתם מגדירים קהילה פעילה, מכיוון שאפשרויות החוזה והדוגמאות מנוהלות בגרסאות יחד עם החבילה ולא יחד עם האתר הזה.

## מתי להשתמש בו

אתגר קריאה לחוזה EVM מתאים במיוחד ל:

- **קהילות מוגבלות בטוקן** שמתירות פרסום רק למחזיקי טוקן.
- **גישה מוגבלת ב-NFT** שבה נדרשת בעלות על NFT מסוים.
- **מרחבי ממשל של DAO** שבהם ההשתתפות מוגבלת למחזיקי טוקן הממשל.

לקהילות שאינן נשענות על זהות בשרשרת, שקלו במקום זאת את [חוסם דואר זבל](./spam-blocker.md) או את [אתגר השוברים](./voucher-challenge.md).
