# אתגר Captcha Canvas

Captcha Canvas Challenge היא חבילת captcha עצמאית מבוססת תמונה לקהילות Bitsocial. היא מציירת טקסט אקראי על גבי canvas ומאפשרת לקהילה לדרוש ממחברים לפתור את התמונה לפני שפרסום מתקבל.

- **קוד מקור ו-README עדכני:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **חבילת npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## התקנה

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## איפה זה משתלב

אתגרי captcha שימושיים כאשר קהילה רוצה שער אינטראקטיבי פשוט להתגוננות בסיסית מפני ספאם. החבילה הזו צרה בכוונה: היא מספקת את מימוש האתגר, בעוד שהקהילה או צומת ה-Bitsocial מחליטים מתי וכיצד להציג אותו.

להגנה חזקה יותר, שלבו אותה עם מערכות ניהול רחבות יותר או עם ניקוד סיכונים, במקום להתייחס ל-captcha כאסטרטגיית אנטי-ספאם שלמה.
