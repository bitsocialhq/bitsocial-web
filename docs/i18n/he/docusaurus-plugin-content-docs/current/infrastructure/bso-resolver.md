# פותר BSO

BSO Resolver מתרגם שמות מתחם `.bso` למפתחות הציבוריים המתאימים להם באמצעות קריאת רשומות TXT של Bitsocial. זו חבילת הפענוח שכלי Bitsocial משתמשים בה כאשר שם `.bso` שמוצג למשתמש צריך להפוך לחומר המפתח שמחסנית העמית לעמית מבינה.

- **קוד המקור וה-README העדכני:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **חבילת npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## התקנה

```bash
npm install @bitsocial/bso-resolver
```

## היכן זה משתלב

שמות Bitsocial נועדו לשמש נקודות כניסה קריאות לבני אדם עבור קהילות ויוצרים. הפותר שומר על שכבת השמות הזו נפרדת מקוד האפליקציה, כך שלקוחות יכולים לבדוק אם שם נתמך ואז לפענח אותו דרך נקודת הכניסה של החבילה המתאימה לסביבת הריצה.

השתמשו בו כשאתם משלבים לקוח, כלי שורת פקודה או שירות מודעי Bitsocial שצריכים לקבל שמות `.bso` ולא רק מפתחות ציבוריים גולמיים.
