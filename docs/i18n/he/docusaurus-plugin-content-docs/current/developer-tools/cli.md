# Bitsocial CLI

`bitsocial-cli` הוא כלי שורת פקודה לעבודה מול צד השרת של פרוטוקול Bitsocial. הוא מאפשר להריץ דימון P2P מקומי, ליצור ולהגדיר קהילות ולפרסם תוכן -- הכול מהטרמינל.

הוא בנוי מעל שכבת לקוח הפרוטוקול המשותפת של Bitsocial, ו-[5chan](/apps/5chan/) ו-[Seedit](/apps/seedit/) משתמשים בו ליצירת קהילות ולניהול צמתים.

## התקנה

קבצים בינאריים מוכנים מראש זמינים עבור Windows, macOS ו-Linux. הורידו את הגרסה האחרונה עבור הפלטפורמה שלכם מ-GitHub:

**[הורדה מ-GitHub Releases](https://github.com/bitsocialnet/bitsocial-cli/releases)**

לאחר ההורדה, הפכו את הקובץ הבינארי לבר-הרצה (macOS/Linux):

```bash
chmod +x bitsocial
```

## הרצת הדימון

השימוש הנפוץ ביותר ב-CLI הוא הרצת צומת Bitsocial. הדימון מפעיל את שכבת הרשת של P2P וחושף API מקומי שלקוחות יכולים להתחבר אליו.

```bash
bitsocial daemon
```

בהפעלה הראשונה הדימון מדפיס קישורים ל-**WebUI**, ממשק גרפי מבוסס דפדפן לניהול הצומת, הקהילות וההגדרות שלכם. זה שימושי אם אתם מעדיפים ממשק גרפי על פני פקודות טרמינל.

## פעולות עיקריות

| פעולה               | תיאור                                     |
| ------------------- | ----------------------------------------- |
| הפעלת הדימון        | הרצת צומת ה-P2P של Bitsocial              |
| יצירת קהילה         | יצירת קהילה חדשה                          |
| עריכת קהילה         | עדכון הגדרות הקהילה (כותרת, תיאור, כללים) |
| הצגת קהילות מקומיות | הצגת הקהילות המתארחות בצומת הזה           |
| הפעלת קהילה         | התחלת שירות של קהילה מסוימת               |
| עצירת קהילה         | הפסקת השירות של קהילה מסוימת              |

הריצו את ה-CLI עם `--help` כדי לראות את שמות הפקודות והדגלים העדכניים שהגרסה המותקנת שלכם חושפת:

```bash
bitsocial --help
bitsocial daemon --help
```

## תהליך עבודה טיפוסי

תהליך הגדרה נפוץ לאירוח קהילה חדשה:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

משם, השתמשו בפקודות ניהול הקהילות של הגרסה המותקנת כדי ליצור קהילה, להגדיר אותה ולהתחיל לשרת אותה. לאחר ההפעלה הקהילה חיה ברשת Bitsocial ונגישה מלקוחות תואמים.
