# Captcha Canvas Challenge

Captcha Canvas Challenge è un pacchetto autonomo di captcha a immagini per le comunità Bitsocial. Disegna del testo casuale su un canvas e permette a una comunità di chiedere agli autori di risolvere l'immagine prima che una pubblicazione venga accettata.

- **Codice sorgente e README aggiornato:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **Pacchetto npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## Installazione

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## Dove si colloca

Le sfide captcha sono utili quando una comunità vuole un filtro interattivo semplice per una resistenza allo spam a basso rischio. Questo pacchetto è volutamente ristretto: fornisce l'implementazione della sfida, mentre sono la comunità o il nodo Bitsocial a decidere quando e come presentarla.

Per una protezione più forte, combinalo con sistemi più ampi di moderazione o di valutazione del rischio, invece di trattare un captcha come una strategia anti-spam completa.
