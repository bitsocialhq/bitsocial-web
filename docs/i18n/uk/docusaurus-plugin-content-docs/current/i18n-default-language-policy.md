# Політика мови за замовчуванням в i18n

Для анонімних відвідувачів мова визначається в такому порядку:

1. Параметр запиту `?lang=`
2. Збережений вибір у перемикачі мов (`localStorage` у браузері, продубльований у cookie `i18nextLng` для SSR)
3. Мова браузера чи пристрою, якщо вона є однією з підтримуваних локалей
4. Запасний варіант — `en`

Країна чи регіон не використовуються для перевизначення підтримуваної мови браузера або пристрою. Наприклад, `de-DE` розпізнається як німецька, `nl-NL` — як нідерландська, а `pt-PT` — як португальська, бо ці сімейства локалей підтримуються.

Якщо жодна мова браузера чи пристрою не збігається з підтримуваною локаллю, відвідувачі отримують англійську за замовчуванням.
