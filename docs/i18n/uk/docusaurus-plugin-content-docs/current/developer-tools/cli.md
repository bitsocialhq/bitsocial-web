# Bitsocial CLI

`bitsocial-cli` — це інструмент командного рядка для роботи з бекендом протоколу Bitsocial. Він дозволяє запустити локальний одноранговий демон, створювати й налаштовувати спільноти та публікувати вміст — усе це з терміналу.

Він побудований на спільному клієнтському шарі протоколу Bitsocial, і його використовують [5chan](/apps/5chan/) та [Seedit](/apps/seedit/) для створення спільнот і керування вузлом.

## Встановлення

Готові збірки доступні для Windows, macOS і Linux. Завантажте найновіший випуск для своєї платформи з GitHub:

**[Завантажити з GitHub Releases](https://github.com/bitsocialnet/bitsocial-cli/releases)**

Після завантаження зробіть файл виконуваним (macOS/Linux):

```bash
chmod +x bitsocial
```

## Запуск демона

Найпоширеніший сценарій використання CLI — це запуск вузла Bitsocial. Демон піднімає одноранговий мережевий шар і відкриває локальний API, до якого можуть під’єднуватися клієнти.

```bash
bitsocial daemon
```

Під час першого запуску демон виводить посилання на **WebUI** — графічний інтерфейс у браузері для керування вузлом, спільнотами й налаштуваннями. Це зручно, якщо ви віддаєте перевагу графічному інтерфейсу перед командами в терміналі.

## Основні дії

| Дія                         | Опис                                                  |
| --------------------------- | ----------------------------------------------------- |
| Запустити демон             | Запустити одноранговий вузол Bitsocial                |
| Створити спільноту          | Створити нову спільноту                               |
| Змінити спільноту           | Оновити налаштування спільноти (назва, опис, правила) |
| Показати локальні спільноти | Показати спільноти, розміщені на цьому вузлі          |
| Запустити спільноту         | Почати обслуговувати конкретну спільноту              |
| Зупинити спільноту          | Припинити обслуговувати конкретну спільноту           |

Запустіть CLI з `--help`, щоб побачити актуальні назви команд і прапорці у встановленому вами випуску:

```bash
bitsocial --help
bitsocial daemon --help
```

## Типовий сценарій

Звичайний порядок дій для розміщення нової спільноти:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

Далі скористайтеся командами керування спільнотами зі встановленого випуску, щоб створити, налаштувати й почати обслуговувати спільноту. Після запуску спільнота стає доступною в мережі Bitsocial із сумісних клієнтів.
