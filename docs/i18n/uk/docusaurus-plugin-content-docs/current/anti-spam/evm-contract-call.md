# EVM Contract Call Challenge

EVM Contract Call Challenge перевіряє ончейн-стан автора, перш ніж дозволити публікацію. Власники спільнот можуть вимагати, щоб гаманець або визначена ідентичність задовольняли умову смартконтракту, доступну лише для читання, — наприклад, наявність мінімального балансу токена — перш ніж щось публікувати.

- **Вихідний код і актуальний README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **Пакет npm:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## Встановлення

```bash
npm install @bitsocial/evm-contract-challenge
```

## Де це доречно

Використовуйте цей виклик у спільнотах, де участь має залежати від зовнішнього сигналу EVM: володіння токеном, володіння NFT, оцінки підтвердження людяності, членства в управлінні або іншої умови, яку можна прочитати з контракту.

З погляду автора налаштований виклик спрацьовує автоматично. Він перевіряє придатні джерела гаманця чи ідентичності, викликає вказаний метод контракту й порівнює отримане значення з умовою спільноти.

## Актуальний опис пакета

Ця сторінка навмисно є оглядом, а не дзеркалом довідника з налаштування. Джерелом істини щодо назв викликів, прикладів для Bitsocial CLI, реєстрації в pkc-js, значень параметрів за замовчуванням, прикладів ABI, поведінки RPC та підтримуваних джерел гаманців є README пакета:

- [README EVM Contract Challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)

Налаштовуючи живу спільноту, орієнтуйтеся на README в апстрімі, бо параметри контракту та приклади версіонуються разом із самим пакетом, а не з цим сайтом.

## Коли його використовувати

EVM Contract Call Challenge найкраще підходить для:

- **Спільнот із доступом за токеном**, які дозволяють публікувати лише власникам токена.
- **Доступу за NFT**, коли потрібне володіння конкретним NFT.
- **Просторів управління DAO**, де участь обмежена власниками токена управління.

Для спільнот, які не покладаються на ончейн-ідентичність, розгляньте натомість [Spam Blocker](./spam-blocker.md) або [Voucher Challenge](./voucher-challenge.md).
