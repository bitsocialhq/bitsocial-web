# Voucher Challenge

Voucher Challenge обмежує публікацію контенту унікальними кодами ваучерів, які роздає власник спільноти. Замість того щоб покладатися на автоматичне оцінювання, він переносить довіру на ручний процес запрошень, де відомі люди отримують коди через канал, підконтрольний власнику.

- **Вихідний код і актуальний README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **Пакет npm:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## Встановлення

```bash
npm install @bitsocial/voucher-challenge
```

## Як це працює

1. Власник спільноти генерує один або кілька унікальних кодів ваучерів.
2. Власник роздає ці коди довіреним авторам через канал на свій вибір (особисте повідомлення, електронна пошта, особиста передача тощо).
3. Коли автор намагається щось опублікувати, система викликів просить у нього код ваучера.
4. Код перевіряється — якщо він справжній і ще не був використаний, публікацію приймають.

Після використання кожен код ваучера прив’язується до конкретного автора, тож інші не можуть скористатися ним повторно.

## Коли його використовувати

Voucher Challenge найкраще підходить для:

- **Спільнот лише за запрошенням**, де членство свідомо обмежене.
- **Кураторських просторів**, де власник особисто перевіряє кожного учасника.
- **Середовищ із високою довірою**, де автоматичне оцінювання спаму зайве або небажане.

Оскільки він потребує ручної роздачі кодів, він не масштабується на великі відкриті спільноти. Для таких сценаріїв розгляньте [Spam Blocker](./spam-blocker.md) або [EVM Contract Call Challenge](./evm-contract-call.md).
