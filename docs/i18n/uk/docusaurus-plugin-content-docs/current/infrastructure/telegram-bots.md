# Telegram-боти

Telegram-боти Bitsocial відстежують клієнтські списки спільнот у мережі Bitsocial і автоматично пересилають нові дописи в канали Telegram. Кожне переслане повідомлення містить вбудовані кнопки, які ведуть до оригінального допису на 5chan і Seedit.

- **GitHub**: [bitsocialnet/bitsocial-telegram-bots](https://github.com/bitsocialnet/bitsocial-telegram-bots)

## Доступні боти

| Бот                | Стан        | Опис                                                             |
| ------------------ | ----------- | ---------------------------------------------------------------- |
| **Стрічка 5chan**  | Активний    | Відстежує всі каталоги 5chan і пересилає нові дописи в Telegram. |
| **Стрічка Seedit** | Заплановано | Забезпечуватиме ту саму функціональність для спільнот Seedit.    |

## Налаштування

### Вимоги

- Node.js
- Yarn
- Токен бота Telegram (створіть його через [BotFather](https://t.me/BotFather))

### Встановлення

Клонуйте репозиторій і встановіть залежності:

```bash
git clone https://github.com/bitsocialnet/bitsocial-telegram-bots.git
cd bitsocial-telegram-bots
yarn install
```

### Конфігурація

Створіть файл `.env` у корені проєкту й додайте туди токен свого бота:

```env
BOT_TOKEN=your_telegram_bot_token
```

### Запуск

Після налаштування середовища запустіть бота:

```bash
yarn start
```

## Формат допису

Коли бот пересилає допис у Telegram, він додає дві вбудовані кнопки:

- **Переглянути на 5chan** — відкриває допис у вебклієнті 5chan.
- **Переглянути на Seedit** — відкриває допис у вебклієнті Seedit.

Завдяки цьому підписники Telegram можуть одразу перейти до повного обговорення в тому клієнті, який їм зручніший.
