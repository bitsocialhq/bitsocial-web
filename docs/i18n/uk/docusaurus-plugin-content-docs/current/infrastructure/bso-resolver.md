# BSO Resolver

BSO Resolver перетворює доменні імена `.bso` на відповідні їм відкриті ключі, зчитуючи записи Bitsocial TXT. Це той самий пакет-резолвер, який використовують інструменти Bitsocial, коли зрозуміле людині ім’я `.bso` потрібно перетворити на ключовий матеріал, зрозумілий одноранговому стеку.

- **Вихідний код і актуальний README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **Пакет npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## Встановлення

```bash
npm install @bitsocial/bso-resolver
```

## Де він застосовується

Імена Bitsocial задумані як зрозумілі людині точки входу до спільнот і авторів. Резолвер тримає цей шар іменування окремо від коду застосунку, тож клієнти можуть спершу запитати, чи підтримується ім’я, а потім розв’язати його через відповідну для свого середовища точку входу пакета.

Використовуйте його, коли інтегруєте клієнт, інструмент командного рядка або службу з підтримкою Bitsocial, яким потрібно приймати імена `.bso`, а не лише сирі відкриті ключі.

## Актуальний опис пакета

Ця сторінка навмисно є оглядом, а не копією довідника API. Джерелом правди щодо параметрів конструктора, типів, що повертаються, поведінки кешування, точок входу, прикладів провайдерів і підтримуваної семантики завершення роботи є README пакета:

- [README BSO Resolver](https://github.com/bitsocialnet/bso-resolver#readme)

Копіюючи код у проєкт, орієнтуйтеся саме на README в репозиторії, бо поведінка резолвера версіонується разом із пакетом, а не разом із цим сайтом.
