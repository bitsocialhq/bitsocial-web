# i18n डिफ़ॉल्ट भाषा नीति

अनाम विज़िटर के लिए भाषा इस क्रम में तय होती है:

1. `?lang=` क्वेरी पैरामीटर
2. भाषा चयनकर्ता में सहेजा गया विकल्प (ब्राउज़र में `localStorage`, जिसे SSR के लिए `i18nextLng` कुकी में मिरर किया जाता है)
3. ब्राउज़र/डिवाइस की भाषा, जब वह हमारे समर्थित लोकेल में से एक हो
4. `en` पर वापस लौटना

समर्थित ब्राउज़र/डिवाइस भाषा को ओवरराइड करने के लिए देश या क्षेत्र का उपयोग नहीं किया जाता। उदाहरण के लिए, `de-DE` जर्मन में, `nl-NL` डच में और `pt-PT` पुर्तगाली में हल होता है, क्योंकि ये लोकेल परिवार समर्थित हैं।

अगर ब्राउज़र/डिवाइस की कोई भी भाषा किसी समर्थित लोकेल से मेल नहीं खाती, तो विज़िटर को अंग्रेज़ी डिफ़ॉल्ट मिलता है।
