# Bitsocial CLI

`bitsocial-cli` एक कमांड-लाइन टूल है, जिससे Bitsocial प्रोटोकॉल बैकएंड के साथ इंटरैक्ट किया जाता है। यह आपको स्थानीय P2P डेमन चलाने, समुदाय बनाने और कॉन्फ़िगर करने, तथा सामग्री प्रकाशित करने देता है -- वह भी पूरी तरह टर्मिनल से।

यह साझा Bitsocial प्रोटोकॉल क्लाइंट परत पर बना है, और समुदाय बनाने तथा नोड प्रबंधन के लिए [5chan](/apps/5chan/) और [Seedit](/apps/seedit/) इसका उपयोग करते हैं।

## इंस्टॉलेशन

Windows, macOS और Linux के लिए पहले से बनी बाइनरी उपलब्ध हैं। अपने प्लेटफ़ॉर्म के लिए नवीनतम रिलीज़ GitHub से डाउनलोड करें:

**[GitHub Releases से डाउनलोड करें](https://github.com/bitsocialnet/bitsocial-cli/releases)**

डाउनलोड के बाद बाइनरी को निष्पादन योग्य बनाएँ (macOS/Linux):

```bash
chmod +x bitsocial
```

## डेमन चलाना

CLI का सबसे आम उपयोग Bitsocial नोड चलाना है। डेमन P2P नेटवर्किंग परत शुरू करता है और एक स्थानीय API उपलब्ध कराता है, जिससे क्लाइंट जुड़ सकते हैं।

```bash
bitsocial daemon
```

पहली बार शुरू होने पर डेमन **WebUI** के लिंक दिखाता है — यह ब्राउज़र-आधारित ग्राफ़िकल इंटरफ़ेस है, जिससे आप अपना नोड, समुदाय और सेटिंग्स प्रबंधित कर सकते हैं। यदि आपको टर्मिनल कमांड के बजाय GUI पसंद है, तो यह उपयोगी है।

## प्रमुख क्रियाएँ

| क्रिया                       | विवरण                                            |
| ---------------------------- | ------------------------------------------------ |
| डेमन शुरू करें               | Bitsocial P2P नोड चालू करें                      |
| समुदाय बनाएँ                 | नया समुदाय बनाएँ                                 |
| समुदाय संपादित करें          | समुदाय सेटिंग्स अपडेट करें (शीर्षक, विवरण, नियम) |
| स्थानीय समुदाय सूचीबद्ध करें | इस नोड पर होस्ट किए गए समुदाय सूचीबद्ध करें      |
| समुदाय शुरू करें             | किसी विशिष्ट समुदाय को परोसना शुरू करें          |
| समुदाय रोकें                 | किसी विशिष्ट समुदाय को परोसना बंद करें           |

अपने इंस्टॉल किए गए रिलीज़ में उपलब्ध वर्तमान कमांड नाम और फ़्लैग देखने के लिए CLI को `--help` के साथ चलाएँ:

```bash
bitsocial --help
bitsocial daemon --help
```

## सामान्य वर्कफ़्लो

नया समुदाय होस्ट करने के लिए एक आम सेटअप प्रवाह:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

वहाँ से, समुदाय बनाने, कॉन्फ़िगर करने और उसे परोसना शुरू करने के लिए इंस्टॉल किए गए रिलीज़ के समुदाय-प्रबंधन कमांड उपयोग करें। शुरू होते ही समुदाय Bitsocial नेटवर्क पर लाइव हो जाता है और संगत क्लाइंट से उस तक पहुँचा जा सकता है।
