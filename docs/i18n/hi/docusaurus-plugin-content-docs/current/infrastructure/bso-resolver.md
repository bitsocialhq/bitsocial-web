# BSO Resolver

BSO Resolver, Bitsocial TXT रिकॉर्ड पढ़कर `.bso` डोमेन नामों को उनकी संगत सार्वजनिक कुंजियों में बदल देता है। जब किसी उपयोगकर्ता-सामने दिखने वाले `.bso` नाम को उस कुंजी सामग्री में बदलना होता है जिसे पीयर-टू-पीयर स्टैक समझता है, तब Bitsocial टूलिंग यही रिज़ॉल्वर पैकेज उपयोग करती है।

- **स्रोत कोड और वर्तमान README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **npm पैकेज:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## इंस्टॉलेशन

```bash
npm install @bitsocial/bso-resolver
```

## यह कहाँ फ़िट होता है

Bitsocial नाम समुदायों और लेखकों के लिए मनुष्य-पठनीय प्रवेश-बिंदु के रूप में सोचे गए हैं। रिज़ॉल्वर उस नामकरण परत को ऐप्लिकेशन कोड से अलग रखता है, ताकि क्लाइंट पहले यह पूछ सकें कि कोई नाम समर्थित है या नहीं और फिर उसे पैकेज के रनटाइम-विशिष्ट प्रवेश-बिंदु के ज़रिए हल कर सकें।

इसका उपयोग तब करें जब आप ऐसा Bitsocial-सचेत क्लाइंट, कमांड-लाइन टूल या सेवा जोड़ रहे हों जिसे केवल कच्ची सार्वजनिक कुंजियों के बजाय `.bso` नाम भी स्वीकार करने हों।

## वर्तमान पैकेज संदर्भ

यह पृष्ठ जानबूझकर एक अवलोकन है, नक़ल किया गया API संदर्भ नहीं। कंस्ट्रक्टर विकल्प, रिटर्न टाइप, कैशिंग व्यवहार, प्रवेश-बिंदु, प्रोवाइडर उदाहरण और समर्थित शटडाउन सिमैंटिक्स के लिए पैकेज का README ही सत्य का स्रोत है:

- [BSO Resolver README](https://github.com/bitsocialnet/bso-resolver#readme)

किसी प्रोजेक्ट में कोड कॉपी करते समय अपस्ट्रीम README को प्राथमिकता दें, क्योंकि रिज़ॉल्वर का व्यवहार इस वेबसाइट के बजाय उसी पैकेज के साथ संस्करणित होता है।
