# कैप्चा कैनवास चुनौती

कैप्चा कैनवास चुनौती Bitsocial समुदायों के लिए एक स्वतंत्र इमेज-कैप्चा पैकेज है। यह एक कैनवास पर बेतरतीब टेक्स्ट बनाता है और समुदाय को यह सुविधा देता है कि किसी प्रकाशन को स्वीकार करने से पहले लेखकों से वह छवि हल करवाई जाए।

- **स्रोत कोड और मौजूदा README:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **npm पैकेज:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## इंस्टॉलेशन

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## यह कहाँ फिट बैठती है

कैप्चा चुनौतियाँ तब उपयोगी होती हैं जब किसी समुदाय को कम जोखिम वाली स्पैम रोकथाम के लिए एक सरल, इंटरैक्टिव गेट चाहिए। यह पैकेज जानबूझकर सीमित रखा गया है: यह केवल चुनौती का क्रियान्वयन देता है, जबकि उसे कब और कैसे दिखाना है, यह समुदाय या Bitsocial नोड तय करता है।

ज़्यादा मज़बूत सुरक्षा के लिए कैप्चा को अपने-आप में पूरी एंटी-स्पैम रणनीति मानने के बजाय उसे व्यापक मॉडरेशन या जोखिम-स्कोरिंग प्रणालियों के साथ जोड़ें।

## मौजूदा पैकेज संदर्भ

यह पृष्ठ जानबूझकर एक अवलोकन है, सेटअप गाइड की नक़ल नहीं। मौजूदा चुनौती नामों, पंजीकरण उदाहरणों, CLI उदाहरणों, समर्थित विकल्पों, आवश्यकताओं और सुरक्षा टिप्पणियों के लिए पैकेज का README ही प्रामाणिक स्रोत है:

- [कैप्चा कैनवास चुनौती का README](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)

किसी चालू समुदाय को कॉन्फ़िगर करते समय अपस्ट्रीम README को प्राथमिकता दें, क्योंकि पैकेज के विकल्प और इंस्टॉल प्रवाह इस वेबसाइट के बजाय उसी पैकेज के साथ संस्करणित होते हैं।
