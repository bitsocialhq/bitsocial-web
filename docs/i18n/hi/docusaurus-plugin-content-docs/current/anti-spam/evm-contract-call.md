# EVM कॉन्ट्रैक्ट कॉल चुनौती

EVM कॉन्ट्रैक्ट कॉल चुनौती किसी प्रकाशन की अनुमति देने से पहले लेखक की ऑन-चेन स्थिति की पुष्टि करती है। समुदाय के मालिक यह शर्त रख सकते हैं कि पोस्ट करने से पहले कोई वॉलेट या हल की गई पहचान किसी केवल-पढ़ने वाली स्मार्ट-कॉन्ट्रैक्ट शर्त पर खरी उतरे, जैसे कि न्यूनतम टोकन बैलेंस रखना।

- **स्रोत कोड और मौजूदा README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **npm पैकेज:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## इंस्टॉलेशन

```bash
npm install @bitsocial/evm-contract-challenge
```

## यह कहाँ फिट बैठती है

इस चुनौती का उपयोग उन समुदायों के लिए करें जहाँ भागीदारी किसी बाहरी EVM संकेत पर निर्भर होनी चाहिए: टोकन का स्वामित्व, NFT का स्वामित्व, प्रूफ़-ऑफ़-पर्सनहुड स्कोर, गवर्नेंस सदस्यता, या कोई और शर्त जिसे कॉन्ट्रैक्ट से पढ़ा जा सके।

एक बार कॉन्फ़िगर हो जाने के बाद, लेखक के नज़रिए से यह चुनौती अपने आप चलती है। यह पात्र वॉलेट या पहचान स्रोतों की जाँच करती है, कॉन्फ़िगर की गई कॉन्ट्रैक्ट मेथड को कॉल करती है, और लौटे हुए मान की तुलना समुदाय की शर्त से करती है।

## मौजूदा पैकेज संदर्भ

यह पृष्ठ जानबूझकर एक अवलोकन है, कॉन्फ़िगरेशन संदर्भ की नक़ल नहीं। चुनौती नामों, Bitsocial CLI उदाहरणों, pkc-js पंजीकरण, विकल्पों के डिफ़ॉल्ट, ABI उदाहरणों, RPC व्यवहार और समर्थित वॉलेट स्रोतों के लिए पैकेज का README ही प्रामाणिक स्रोत है:

- [EVM कॉन्ट्रैक्ट चुनौती का README](https://github.com/bitsocialnet/evm-contract-challenge#readme)

किसी चालू समुदाय को कॉन्फ़िगर करते समय अपस्ट्रीम README को प्राथमिकता दें, क्योंकि कॉन्ट्रैक्ट संबंधी विकल्प और उदाहरण इस वेबसाइट के बजाय उसी पैकेज के साथ संस्करणित होते हैं।

## इसका उपयोग कब करें

EVM कॉन्ट्रैक्ट कॉल चुनौती इनके लिए आदर्श है:

- **टोकन-गेटेड समुदाय** जो पोस्ट करने की अनुमति केवल टोकन धारकों तक सीमित रखते हैं।
- **NFT-गेटेड पहुँच**, जहाँ किसी विशिष्ट NFT का स्वामित्व ज़रूरी है।
- **DAO गवर्नेंस स्पेस**, जहाँ भागीदारी गवर्नेंस टोकन धारकों तक सीमित है।

जो समुदाय ऑन-चेन पहचान पर निर्भर नहीं हैं, उनके लिए इसके बजाय [स्पैम अवरोधक](./spam-blocker.md) या [वाउचर चुनौती](./voucher-challenge.md) पर विचार करें।
