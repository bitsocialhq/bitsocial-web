# वाउचर चुनौती

वाउचर चुनौती सामग्री के प्रकाशन को समुदाय के मालिक द्वारा बाँटे गए अनोखे वाउचर कोड के पीछे रखती है। स्वचालित स्कोरिंग पर भरोसा करने के बजाय, यह भरोसे को एक मैनुअल आमंत्रण प्रवाह पर टिका देती है, जहाँ जाने-पहचाने लोगों को कोड ऐसे माध्यम से मिलते हैं जिस पर मालिक का नियंत्रण होता है।

- **स्रोत कोड और मौजूदा README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **npm पैकेज:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## इंस्टॉलेशन

```bash
npm install @bitsocial/voucher-challenge
```

## यह कैसे काम करती है

1. समुदाय का मालिक एक या एक से ज़्यादा अनोखे वाउचर कोड बनाता है।
2. मालिक वे कोड अपनी पसंद के माध्यम से (सीधा संदेश, ईमेल, आमने-सामने, आदि) भरोसेमंद लेखकों तक पहुँचाता है।
3. जब कोई लेखक प्रकाशित करने की कोशिश करता है, तो चुनौती प्रणाली उससे वाउचर कोड माँगती है।
4. कोड की जाँच होती है -- अगर वह असली है और पहले इस्तेमाल नहीं हुआ है, तो प्रकाशन स्वीकार कर लिया जाता है।

एक बार भुनाए जाने के बाद हर वाउचर कोड किसी एक लेखक से जुड़ जाता है, जिससे दूसरे लोग उसे दोबारा इस्तेमाल नहीं कर पाते।

## मौजूदा पैकेज संदर्भ

यह पृष्ठ जानबूझकर एक अवलोकन है, सेटअप गाइड की नक़ल नहीं। मौजूदा चुनौती नामों, Bitsocial CLI उदाहरणों, pkc-js पंजीकरण, समर्थित विकल्पों और भुनाने के व्यवहार के लिए पैकेज का README ही प्रामाणिक स्रोत है:

- [वाउचर चुनौती का README](https://github.com/bitsocialnet/voucher-challenge#readme)

किसी चालू समुदाय को कॉन्फ़िगर करते समय अपस्ट्रीम README को प्राथमिकता दें, क्योंकि वाउचर संबंधी विकल्प और इंस्टॉल प्रवाह इस वेबसाइट के बजाय उसी पैकेज के साथ संस्करणित होते हैं।

## इसका उपयोग कब करें

वाउचर चुनौती इनके लिए सबसे उपयुक्त है:

- **केवल-आमंत्रण वाले समुदाय**, जहाँ सदस्यता जानबूझकर सीमित रखी जाती है।
- **क्यूरेट किए गए स्पेस**, जहाँ मालिक हर भागीदार को खुद परखता है।
- **उच्च-भरोसे वाले माहौल**, जहाँ स्वचालित स्पैम स्कोरिंग की ज़रूरत नहीं है या वह वांछनीय नहीं है।

चूँकि इसमें कोड मैनुअल तरीक़े से बाँटने पड़ते हैं, यह बड़े और खुले समुदायों के लिए व्यावहारिक नहीं है। ऐसी स्थितियों के लिए इसके बजाय [स्पैम अवरोधक](./spam-blocker.md) या [EVM कॉन्ट्रैक्ट कॉल चुनौती](./evm-contract-call.md) पर विचार करें।
