# i18n デフォルト言語ポリシー

匿名の訪問者に対する言語は、次の順序で決定されます。

1. `?lang=` クエリパラメータ
2. 保存済みの言語セレクタの選択（ブラウザでは `localStorage` に保存し、SSR 用に `i18nextLng` クッキーへ反映）
3. ブラウザ／デバイスの言語が対応ロケールのいずれかである場合は、その言語
4. 最後は `en` にフォールバック

国や地域によって、対応しているブラウザ／デバイスの言語が上書きされることはありません。たとえば `de-DE` はドイツ語、`nl-NL` はオランダ語、`pt-PT` はポルトガル語として解決されます。これらのロケールファミリーに対応しているためです。

ブラウザ／デバイスの言語が対応ロケールのいずれとも一致しない場合、訪問者には既定の英語が表示されます。
