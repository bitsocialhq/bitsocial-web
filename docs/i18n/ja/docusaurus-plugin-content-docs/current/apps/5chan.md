# 5chan

5chan は、Bitsocial プロトコル上で動作する、サーバーレスで管理者を置かない、完全に分散化されたイメージボードです。おなじみのイメージボードのディレクトリ構造を踏襲しながら、分散型の所有という仕組みを持ち込んでいます。誰でも板を作成でき、複数の板が投票の仕組みを通じて同じディレクトリスロットを争えます。

## 板の仕組み

5chan は、古典的なディレクトリ構成 (`/b/`、`/g/` など) を使ってコンテンツを板に整理します。すべての板を中央の管理者が仕切る従来のイメージボードとは違い、5chan ではどのユーザーも自分の板を作成し、完全に所有できます。複数の板が同じディレクトリスロットを狙う場合は、投票によってその位置を争います。

### 板を作成する

新しい板を作成するには、`bitsocial-cli` をピアツーピアノードとして実行する必要があります。これにより、板は中央サーバーに頼ることなく、分散した形でホストされます。

### ディレクトリの割り当て

ディレクトリスロットの割り当て (どの板がどのパスに現れるか) は、現時点では `5chan-directories.json` ファイルへの GitHub プルリクエストで管理されています。これは暫定的な仕組みです。今後のリリースでは、アプリ内での板の作成と pubsub ベースの投票に対応し、ディレクトリの割り当てを自動で処理できるようになります。

## 内部構造

5chan は内部的に、ネットワークとのやり取りに共通の Bitsocial プロトコルのクライアント層を使っています。
5chan.app のウェブアプリはデフォルトでブラウザ内に Helia ノードを動かすため、普通のタブがそのまま
ピアとしてネットワークに参加します。他のピアから板を読み込み、pubsub 経由で公開するので、コンテンツの
経路に中央集権的な IPFS ゲートウェイは入りません。それが何を伴い、ブラウザのノードにはまだ何ができないのかは、[ブラウザ ピアツーピア](/browser-p2p/) を参照してください。
