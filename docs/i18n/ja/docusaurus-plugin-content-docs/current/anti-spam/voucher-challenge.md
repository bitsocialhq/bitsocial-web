# バウチャーチャレンジ

Voucher Challenge は、コミュニティのオーナーが配布する一意のバウチャーコードによってコンテンツの投稿を制限します。自動的なスコアリングに頼るのではなく、オーナーが管理する経路で顔の見える相手にコードを渡す、手動の招待フローへ信頼の置きどころを移します。

- **ソースコードと最新の README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **npm パッケージ:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## インストール

```bash
npm install @bitsocial/voucher-challenge
```

## 仕組み

1. コミュニティのオーナーが、一意のバウチャーコードを 1 つ以上生成します。
2. オーナーは、自分で選んだ経路 (ダイレクトメッセージ、メール、対面など) で、信頼できる作成者にそのコードを配ります。
3. 作成者が投稿しようとすると、チャレンジの仕組みがバウチャーコードの入力を求めます。
4. コードが検証されます。正規のもので、まだ使われていなければ、その投稿は受け入れられます。

各バウチャーコードは、一度使われると特定の作成者に紐づき、他の人による再利用を防ぎます。

## いつ使うか

Voucher Challenge がいちばん向いているのは次のような場合です。

- **招待制のコミュニティ** — 参加者を意図的に限定している場合。
- **キュレーションされた場** — オーナーが参加者ひとりひとりを自ら確認する場合。
- **信頼度の高い環境** — 自動のスパムスコアリングが不要、または望ましくない場合。

コードを手作業で配る必要があるため、大規模で開かれたコミュニティには向きません。そうした場合は、代わりに [スパムブロッカー](./spam-blocker.md) や [EVM コントラクト呼び出しチャレンジ](./evm-contract-call.md) を検討してください。
