# Bitsocial の経済圏を拡大する

フェーズ 4 の狙いは、単一の企業、RPC、ホスティング事業者、クライアントが新しいプラットフォーム所有者に
なってしまわないところまで、エコシステムを大きくすることです。

最初の公開 RPC と最初の主要サービスは Bitsocial Forge が作れますが、それが最終形であってはなりません。
多くの企業、チーム、匿名の運用者、コミュニティ組織、独立した開発者が Bitsocial の上に有用なインフラを
築けるほど、ネットワークは健全になります。

## 何を拡大する必要があるか

エコシステムに必要なのはアプリだけではありません。

- 競合する公開 RPC
- メディアホスティングのサービス
- 発見とインデックス作成のサービス
- モデレーションのサービス
- フィードアルゴリズムの提供者
- プロフィールノードのホスティング
- 分析と可観測性
- 開発者向けツール
- 助成金と資金提供の経路

どのサービスも差し替え可能であるべきです。有用な提供者が成功するのは構いませんが、ユーザーとアプリには
それでも他に行き先が残っていなければなりません。

## 分散化としての資金提供

資金提供は、ひとつの恒久的なハブへではなく、より多くの独立した運用者へとネットワークを押し進めるもので
あるべきです。

つまり、クライアント、インフラ、モデレーションツール、インデックス作成ツール、モバイル体験、
メディアサービス、競合する RPC を作る開発者に資金を出すということです。同時に、企業、コミュニティ団体、
匿名の運用者、個人の作り手が、ネットワークの内側で持続可能な事業を見つけられる余地を残すということでも
あります。

## 経済圏が重要な理由

ソーシャルのインフラは維持に費用がかかります。RPC、ホスティング、発見、開発の費用をひとつの組織
だけが負担しているなら、プロトコルがピアツーピアであってもネットワークは脆いままです。

より強い形は、プロトコルを取り巻くサービスの市場です。

- クライアントはユーザーを求めて競う
- RPC は信頼性と信頼モデルで競う
- メディアホストは価格とポリシーで競う
- 発見サービスは関連性で競う
- 開発者は助成金、収益、評判を求めて競う

Bitsocial の経済圏は、有用な仕事に多くの独立した担い手が資金を得られるようにすることで、プロトコルを
乗っ取りにくいものにするはずです。
