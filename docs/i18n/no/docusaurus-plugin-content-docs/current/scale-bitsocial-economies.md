# Skaler Bitsocial-økonomier

Fase 4 handler om å gjøre økosystemet stort nok til at ingen enkelt bedrift, RPC, hostingleverandør
eller klient blir den nye plattformeieren.

Bitsocial Forge kan bygge den første offentlige RPC-en og de første store tjenestene, men det bør
ikke være sluttilstanden. Nettverket blir sunnere hvis mange bedrifter, team, anonyme operatører,
fellesskapsenheter og uavhengige utviklere kan bygge nyttig infrastruktur oppå Bitsocial.

## Hva som må skalere

Økosystemet trenger mer enn apper:

- konkurrerende offentlige RPC-er
- tjenester for mediehosting
- tjenester for oppdagelse og indeksering
- modereringstjenester
- leverandører av feedalgoritmer
- hosting av profilnoder
- analyse og observerbarhet
- utviklerverktøy
- stipender og finansieringskanaler

Hver tjeneste bør kunne byttes ut. En nyttig leverandør kan bli en suksess, men brukere og apper
skal fortsatt ha et annet sted å gå.

## Finansiering som desentralisering

Finansiering bør skyve nettverket mot flere uavhengige operatører, ikke mot ett permanent
knutepunkt.

Det betyr å finansiere utviklere som bygger klienter, infrastruktur, modereringsverktøy,
indekseringsverktøy, mobilopplevelser, medietjenester og konkurrerende RPC-er. Det betyr også å la
det være rom for at bedrifter, fellesskapsgrupper, anonyme operatører og enkeltutviklere kan finne
bærekraftige forretningsmodeller inne i nettverket.

## Hvorfor økonomier betyr noe

Sosial infrastruktur er dyr å vedlikeholde. Hvis bare én organisasjon betaler for RPC, hosting,
oppdagelse og utvikling, forblir nettverket skjørt selv om protokollen er peer-to-peer.

Den sterkere varianten er et marked av tjenester rundt protokollen:

- klienter konkurrerer om brukere
- RPC-er konkurrerer på pålitelighet og tillitsmodell
- medieverter konkurrerer på pris og retningslinjer
- oppdagelsestjenester konkurrerer på relevans
- utviklere konkurrerer om stipender, inntekter og omdømme

Bitsocial-økonomier skal gjøre protokollen vanskeligere å ta kontroll over, ved å gjøre nyttig
arbeid finansierbart på tvers av mange uavhengige aktører.
