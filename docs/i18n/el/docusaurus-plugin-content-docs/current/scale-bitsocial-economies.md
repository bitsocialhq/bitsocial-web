# Κλιμάκωση των οικονομιών του Bitsocial

Η Φάση 4 αφορά τη μεγέθυνση του οικοσυστήματος σε τέτοιο βαθμό ώστε καμία μεμονωμένη εταιρεία,
κανένα RPC, κανένας πάροχος φιλοξενίας και κανένας πελάτης να μη γίνει ο νέος ιδιοκτήτης της
πλατφόρμας.

Το Bitsocial Forge μπορεί να φτιάξει το πρώτο δημόσιο RPC και τις πρώτες μεγάλες υπηρεσίες, αλλά
αυτό δεν πρέπει να είναι η τελική κατάσταση. Το δίκτυο είναι πιο υγιές όταν πολλές επιχειρήσεις,
ομάδες, ανώνυμοι χειριστές, φορείς κοινοτήτων και ανεξάρτητοι προγραμματιστές μπορούν να χτίζουν
χρήσιμες υποδομές πάνω στο Bitsocial.

## Τι πρέπει να κλιμακωθεί

Το οικοσύστημα χρειάζεται κάτι περισσότερο από εφαρμογές:

- ανταγωνιστικά δημόσια RPC
- υπηρεσίες φιλοξενίας πολυμέσων
- υπηρεσίες ανακάλυψης και ευρετηρίασης
- υπηρεσίες συντονισμού περιεχομένου
- παρόχους αλγορίθμων ροής
- φιλοξενία κόμβων προφίλ
- αναλυτικά στοιχεία και παρατηρησιμότητα
- εργαλεία για προγραμματιστές
- επιχορηγήσεις και κανάλια χρηματοδότησης

Κάθε υπηρεσία πρέπει να είναι αντικαταστάσιμη. Ένας χρήσιμος πάροχος μπορεί να πετύχει, αλλά οι
χρήστες και οι εφαρμογές πρέπει να έχουν πάντα κάπου αλλού να πάνε.

## Η χρηματοδότηση ως αποκέντρωση

Η χρηματοδότηση πρέπει να σπρώχνει το δίκτυο προς περισσότερους ανεξάρτητους χειριστές, όχι προς έναν
μόνιμο κόμβο συγκέντρωσης.

Αυτό σημαίνει χρηματοδότηση προγραμματιστών που φτιάχνουν πελάτες, υποδομές, εργαλεία συντονισμού,
εργαλεία ευρετηρίασης, εμπειρίες για κινητά, υπηρεσίες πολυμέσων και ανταγωνιστικά RPC. Σημαίνει
επίσης να αφήνεται χώρος ώστε εταιρείες, ομάδες κοινοτήτων, ανώνυμοι χειριστές και μεμονωμένοι
δημιουργοί να βρίσκουν βιώσιμα επιχειρηματικά μοντέλα μέσα στο δίκτυο.

## Γιατί έχουν σημασία οι οικονομίες

Η κοινωνική υποδομή έχει υψηλό κόστος συντήρησης. Αν μόνο ένας οργανισμός πληρώνει για RPC,
φιλοξενία, ανακάλυψη και ανάπτυξη, το δίκτυο παραμένει εύθραυστο, ακόμη κι αν το πρωτόκολλο είναι
peer-to-peer.

Η ισχυρότερη εκδοχή είναι μια αγορά υπηρεσιών γύρω από το πρωτόκολλο:

- οι πελάτες ανταγωνίζονται για χρήστες
- τα RPC ανταγωνίζονται στην αξιοπιστία και στο μοντέλο εμπιστοσύνης
- οι πάροχοι φιλοξενίας πολυμέσων ανταγωνίζονται στην τιμή και στην πολιτική τους
- οι υπηρεσίες ανακάλυψης ανταγωνίζονται στη συνάφεια των αποτελεσμάτων
- οι προγραμματιστές ανταγωνίζονται για επιχορηγήσεις, έσοδα και φήμη

Οι οικονομίες του Bitsocial πρέπει να κάνουν το πρωτόκολλο πιο δύσκολο να αιχμαλωτιστεί, καθιστώντας
τη χρήσιμη δουλειά χρηματοδοτήσιμη από πολλούς ανεξάρτητους παράγοντες.
