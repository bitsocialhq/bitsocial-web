# 5chan

Το 5chan είναι ένα imageboard χωρίς διακομιστές, χωρίς διαχειριστή και πλήρως αποκεντρωμένο, που λειτουργεί πάνω στο πρωτόκολλο Bitsocial. Ακολουθεί τη γνώριμη δομή καταλόγου των imageboards, εισάγοντας ταυτόχρονα αποκεντρωμένη ιδιοκτησία — ο καθένας μπορεί να δημιουργήσει έναν πίνακα (board) και πολλοί πίνακες μπορούν να διεκδικήσουν την ίδια θέση στον κατάλογο μέσω ενός μηχανισμού ψηφοφορίας.

## Λήψεις

| Πλατφόρμα                | Σύνδεσμος                            |
| ------------------------ | ------------------------------------ |
| Web                      | [5chan.app](https://5chan.app)       |
| Επιτραπέζιος υπολογιστής | Διαθέσιμο για Mac, Windows και Linux |
| Κινητό                   | Διαθέσιμο για Android                |

## Πώς λειτουργούν οι πίνακες

Το 5chan οργανώνει το περιεχόμενο σε πίνακες, χρησιμοποιώντας μια κλασική διάταξη καταλόγου (π.χ. `/b/`, `/g/`). Σε αντίθεση με τα παραδοσιακά imageboards, όπου ένας κεντρικός διαχειριστής ελέγχει κάθε πίνακα, το 5chan επιτρέπει σε κάθε χρήστη να δημιουργήσει και να κατέχει πλήρως τον δικό του πίνακα. Όταν πολλοί πίνακες στοχεύουν στην ίδια θέση του καταλόγου, τη διεκδικούν μεταξύ τους μέσω ψηφοφορίας.

### Δημιουργία πίνακα

Για να δημιουργήσετε έναν νέο πίνακα, πρέπει να τρέχετε το `bitsocial-cli` ως peer-to-peer κόμβο. Έτσι ο πίνακάς σας φιλοξενείται με αποκεντρωμένο τρόπο, χωρίς να εξαρτάται από κανέναν κεντρικό διακομιστή.

### Αναθέσεις θέσεων στον κατάλογο

Οι αναθέσεις θέσεων στον κατάλογο (ποιος πίνακας εμφανίζεται σε ποια διαδρομή) γίνονται προς το παρόν μέσω pull requests στο GitHub προς το αρχείο `5chan-directories.json`. Πρόκειται για προσωρινή διαδικασία — μελλοντικές εκδόσεις θα υποστηρίζουν δημιουργία πινάκων μέσα από την εφαρμογή και ψηφοφορία βασισμένη σε pubsub, ώστε οι αναθέσεις να γίνονται αυτόματα.

## Εσωτερική λειτουργία

Στο παρασκήνιο, το 5chan χρησιμοποιεί το κοινό επίπεδο πελάτη του πρωτοκόλλου Bitsocial για τις
δικτυακές του λειτουργίες. Η διαδικτυακή εφαρμογή στο 5chan.app εκτελεί από προεπιλογή έναν κόμβο
Helia μέσα στο πρόγραμμα περιήγησης, οπότε μια απλή καρτέλα συμμετέχει στο δίκτυο ως peer: φορτώνει
πίνακες από άλλους peers και δημοσιεύει μέσω pubsub, χωρίς κεντρική πύλη IPFS στη διαδρομή του
περιεχομένου. Δείτε το [Peer-to-Peer στο πρόγραμμα περιήγησης](/browser-p2p/) για το τι συνεπάγεται
αυτό και τι εξακολουθεί να μην μπορεί να κάνει ένας κόμβος μέσα σε πρόγραμμα περιήγησης.
