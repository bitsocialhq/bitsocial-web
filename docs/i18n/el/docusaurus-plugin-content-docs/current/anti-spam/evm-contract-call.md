# Πρόκληση κλήσης συμβολαίου EVM

Το EVM Contract Call Challenge επαληθεύει την on-chain κατάσταση ενός συγγραφέα προτού επιτρέψει μια δημοσίευση. Οι ιδιοκτήτες κοινοτήτων μπορούν να απαιτούν από ένα πορτοφόλι ή μια επιλυμένη ταυτότητα να πληροί μια συνθήκη έξυπνου συμβολαίου μόνο για ανάγνωση, όπως η κατοχή ενός ελάχιστου υπολοίπου token, πριν από την ανάρτηση.

- **Πηγαίος κώδικας και τρέχον README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **Πακέτο npm:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## Εγκατάσταση

```bash
npm install @bitsocial/evm-contract-challenge
```

## Πού ταιριάζει

Χρησιμοποιήστε αυτή την πρόκληση σε κοινότητες όπου η συμμετοχή πρέπει να εξαρτάται από ένα εξωτερικό σήμα EVM: κατοχή token, κατοχή NFT, βαθμολογίες proof-of-personhood, συμμετοχή σε σχήμα διακυβέρνησης ή κάποια άλλη συνθήκη που μπορεί να διαβαστεί από συμβόλαιο.

Από την πλευρά του συγγραφέα, η πρόκληση είναι αυτόματη μόλις ρυθμιστεί. Ελέγχει τις επιλέξιμες πηγές πορτοφολιού ή ταυτότητας, καλεί τη ρυθμισμένη μέθοδο του συμβολαίου και συγκρίνει την τιμή που επιστρέφεται με τη συνθήκη της κοινότητας.

## Τεκμηρίωση του τρέχοντος πακέτου

Η σελίδα αυτή είναι σκόπιμα μια επισκόπηση και όχι αντίγραφο της τεκμηρίωσης ρυθμίσεων. Το README του πακέτου αποτελεί την πηγή αλήθειας για τα ονόματα των προκλήσεων, τα παραδείγματα του Bitsocial CLI, την καταχώριση στο pkc-js, τις προεπιλεγμένες τιμές των επιλογών, τα παραδείγματα ABI, τη συμπεριφορά του RPC και τις υποστηριζόμενες πηγές πορτοφολιών:

- [README του EVM Contract Challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)

Προτιμήστε το README του αποθετηρίου όταν ρυθμίζετε μια ζωντανή κοινότητα, επειδή οι επιλογές και τα παραδείγματα του συμβολαίου εκδίδονται μαζί με το πακέτο και όχι με αυτόν τον ιστότοπο.

## Πότε να το χρησιμοποιήσετε

Το EVM Contract Call Challenge είναι ιδανικό για:

- **Κοινότητες με πρόσβαση βάσει token** που περιορίζουν τις αναρτήσεις στους κατόχους token.
- **Πρόσβαση βάσει NFT**, όπου απαιτείται η κατοχή ενός συγκεκριμένου NFT.
- **Χώρους διακυβέρνησης DAO**, όπου η συμμετοχή περιορίζεται στους κατόχους token διακυβέρνησης.

Για κοινότητες που δεν βασίζονται σε on-chain ταυτότητα, εξετάστε αντ' αυτού το [Spam Blocker](./spam-blocker.md) ή την [Πρόκληση Voucher](./voucher-challenge.md).
