# Πρόκληση Captcha Canvas

Το Captcha Canvas Challenge είναι ένα αυτόνομο πακέτο captcha με εικόνα για κοινότητες Bitsocial. Σχεδιάζει τυχαιοποιημένο κείμενο σε έναν καμβά και επιτρέπει σε μια κοινότητα να ζητά από τους συγγραφείς να λύσουν την εικόνα προτού γίνει δεκτή μια δημοσίευση.

- **Πηγαίος κώδικας και τρέχον README:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **Πακέτο npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## Εγκατάσταση

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## Πού ταιριάζει

Οι προκλήσεις captcha είναι χρήσιμες όταν μια κοινότητα θέλει έναν απλό διαδραστικό φραγμό για βασική προστασία από ανεπιθύμητα μηνύματα. Το πακέτο αυτό είναι σκόπιμα περιορισμένο σε εύρος: παρέχει την υλοποίηση της πρόκλησης, ενώ η κοινότητα ή ο κόμβος Bitsocial αποφασίζει πότε και πώς θα την παρουσιάσει.

Για ισχυρότερη προστασία, συνδυάστε το με ευρύτερα συστήματα συντονισμού ή βαθμολόγησης κινδύνου, αντί να αντιμετωπίζετε ένα captcha ως πλήρη στρατηγική κατά των ανεπιθύμητων μηνυμάτων.
