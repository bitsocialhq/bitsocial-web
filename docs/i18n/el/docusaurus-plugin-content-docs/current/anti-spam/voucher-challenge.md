# Πρόκληση Voucher

Το Voucher Challenge περιορίζει τη δημοσίευση περιεχομένου πίσω από μοναδικούς κωδικούς voucher που μοιράζει ο ιδιοκτήτης της κοινότητας. Αντί να βασίζεται σε αυτοματοποιημένη βαθμολόγηση, μεταφέρει την εμπιστοσύνη σε μια χειροκίνητη ροή προσκλήσεων, όπου γνωστά πρόσωπα λαμβάνουν κωδικούς μέσα από ένα κανάλι που ελέγχει ο ιδιοκτήτης.

- **Πηγαίος κώδικας και τρέχον README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **Πακέτο npm:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## Εγκατάσταση

```bash
npm install @bitsocial/voucher-challenge
```

## Πώς λειτουργεί

1. Ο ιδιοκτήτης μιας κοινότητας δημιουργεί έναν ή περισσότερους μοναδικούς κωδικούς voucher.
2. Ο ιδιοκτήτης μοιράζει τους κωδικούς σε έμπιστους συγγραφείς μέσω καναλιού της επιλογής του (προσωπικό μήνυμα, email, δια ζώσης κ.λπ.).
3. Όταν ένας συγγραφέας επιχειρεί να δημοσιεύσει, το σύστημα πρόκλησης του ζητά έναν κωδικό voucher.
4. Ο κωδικός επικυρώνεται -- αν είναι γνήσιος και δεν έχει ήδη χρησιμοποιηθεί, η δημοσίευση γίνεται δεκτή.

Κάθε κωδικός voucher συνδέεται με έναν συγκεκριμένο συγγραφέα μόλις εξαργυρωθεί, ώστε να μην μπορεί να τον ξαναχρησιμοποιήσει κάποιος άλλος.

## Τεκμηρίωση του τρέχοντος πακέτου

Η σελίδα αυτή είναι σκόπιμα μια επισκόπηση και όχι αντίγραφο του οδηγού εγκατάστασης. Το README του πακέτου αποτελεί την πηγή αλήθειας για τα τρέχοντα ονόματα προκλήσεων, τα παραδείγματα του Bitsocial CLI, την καταχώριση στο pkc-js, τις υποστηριζόμενες επιλογές και τη συμπεριφορά εξαργύρωσης:

Προτιμήστε το README του αποθετηρίου όταν ρυθμίζετε μια ζωντανή κοινότητα, επειδή οι επιλογές των voucher και οι ροές εγκατάστασης εκδίδονται μαζί με το πακέτο και όχι με αυτόν τον ιστότοπο.

## Πότε να το χρησιμοποιήσετε

Η Πρόκληση Voucher ταιριάζει καλύτερα σε:

- **Κοινότητες μόνο με πρόσκληση**, όπου η συμμετοχή είναι σκόπιμα περιορισμένη.
- **Επιμελημένους χώρους**, όπου ο ιδιοκτήτης ελέγχει προσωπικά κάθε συμμετέχοντα.
- **Περιβάλλοντα υψηλής εμπιστοσύνης**, όπου η αυτοματοποιημένη βαθμολόγηση ανεπιθύμητων μηνυμάτων είναι περιττή ή ανεπιθύμητη.

Επειδή απαιτεί χειροκίνητη διανομή κωδικών, δεν κλιμακώνεται σε μεγάλες ανοιχτές κοινότητες. Για τέτοιες περιπτώσεις, εξετάστε αντ' αυτού το [Spam Blocker](./spam-blocker.md) ή την [Πρόκληση κλήσης συμβολαίου EVM](./evm-contract-call.md).
