# Bots του Telegram

Τα bots του Bitsocial για το Telegram παρακολουθούν τις λίστες κοινοτήτων των προγραμμάτων-πελατών στο δίκτυο Bitsocial και προωθούν αυτόματα τις νέες αναρτήσεις σε κανάλια Telegram. Κάθε μήνυμα που προωθείται περιλαμβάνει ενσωματωμένα κουμπιά που οδηγούν πίσω στην αρχική ανάρτηση στο 5chan και στο Seedit.

- **GitHub**: [bitsocialnet/bitsocial-telegram-bots](https://github.com/bitsocialnet/bitsocial-telegram-bots)

## Διαθέσιμα bots

| Bot             | Κατάσταση   | Περιγραφή                                                                              |
| --------------- | ----------- | -------------------------------------------------------------------------------------- |
| **5chan Feed**  | Ενεργό      | Παρακολουθεί όλους τους καταλόγους του 5chan και προωθεί νέες αναρτήσεις στο Telegram. |
| **Seedit Feed** | Σχεδιάζεται | Θα προσφέρει την ίδια λειτουργικότητα για τις κοινότητες του Seedit.                   |

## Ρύθμιση

### Προϋποθέσεις

- Node.js
- Yarn
- Ένα token bot του Telegram (δημιουργήστε ένα μέσω του [BotFather](https://t.me/BotFather))

### Εγκατάσταση

Κλωνοποιήστε το αποθετήριο και εγκαταστήστε τις εξαρτήσεις:

```bash
git clone https://github.com/bitsocialnet/bitsocial-telegram-bots.git
cd bitsocial-telegram-bots
yarn install
```

### Διαμόρφωση

Δημιουργήστε ένα αρχείο `.env` στη ρίζα του έργου με το token του bot σας:

```env
BOT_TOKEN=your_telegram_bot_token
```

### Εκτέλεση

Ξεκινήστε το bot αφού διαμορφώσετε το περιβάλλον σας:

```bash
yarn start
```

## Μορφή ανάρτησης

Όταν το bot προωθεί μια ανάρτηση στο Telegram, περιλαμβάνει δύο ενσωματωμένα κουμπιά:

- **Προβολή στο 5chan** -- Ανοίγει την ανάρτηση στο πρόγραμμα-πελάτη ιστού του 5chan.
- **Προβολή στο Seedit** -- Ανοίγει την ανάρτηση στο πρόγραμμα-πελάτη ιστού του Seedit.

Έτσι, οι συνδρομητές στο Telegram μπορούν να μεταβαίνουν απευθείας στο πλήρες νήμα συζήτησης, στον πελάτη που προτιμούν.
