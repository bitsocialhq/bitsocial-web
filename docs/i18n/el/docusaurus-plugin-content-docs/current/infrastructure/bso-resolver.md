# BSO Resolver

Το BSO Resolver μετατρέπει τα ονόματα τομέα `.bso` στα αντίστοιχα δημόσια κλειδιά τους, διαβάζοντας εγγραφές Bitsocial TXT. Είναι το πακέτο επίλυσης που χρησιμοποιούν τα εργαλεία του Bitsocial όταν ένα όνομα `.bso` που βλέπει ο χρήστης πρέπει να μετατραπεί στο υλικό κλειδιού που κατανοεί η peer-to-peer στοίβα.

- **Πηγαίος κώδικας και τρέχον README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **Πακέτο npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## Εγκατάσταση

```bash
npm install @bitsocial/bso-resolver
```

## Πού εντάσσεται

Τα ονόματα Bitsocial προορίζονται να λειτουργούν ως αναγνώσιμα από ανθρώπους σημεία εισόδου για κοινότητες και συγγραφείς. Το πακέτο επίλυσης κρατά αυτό το επίπεδο ονοματοδοσίας χωριστά από τον κώδικα της εφαρμογής, ώστε τα προγράμματα-πελάτες να μπορούν πρώτα να ρωτούν αν ένα όνομα υποστηρίζεται και έπειτα να το επιλύουν μέσω του σημείου εισόδου που αντιστοιχεί στο περιβάλλον εκτέλεσης.

Χρησιμοποιήστε το όταν ενσωματώνετε ένα πρόγραμμα-πελάτη, εργαλείο γραμμής εντολών ή υπηρεσία με γνώση του Bitsocial που πρέπει να δέχεται ονόματα `.bso` και όχι μόνο ακατέργαστα δημόσια κλειδιά.
