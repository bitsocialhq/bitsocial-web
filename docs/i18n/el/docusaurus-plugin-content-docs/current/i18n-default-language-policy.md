# Πολιτική προεπιλεγμένης γλώσσας i18n

Οι ανώνυμοι επισκέπτες προσδιορίζουν τη γλώσσα με την εξής σειρά:

1. Παράμετρος ερωτήματος `?lang=`
2. Αποθηκευμένη επιλογή από τον επιλογέα γλώσσας (`localStorage` στο πρόγραμμα περιήγησης, με αντίγραφο στο cookie `i18nextLng` για το SSR)
3. Γλώσσα προγράμματος περιήγησης ή συσκευής, όταν ανήκει στις τοπικές ρυθμίσεις που υποστηρίζουμε
4. Επιστροφή στο `en`

Η χώρα ή η περιοχή δεν χρησιμοποιείται για να παρακάμψει μια υποστηριζόμενη γλώσσα προγράμματος περιήγησης ή συσκευής. Για παράδειγμα, το `de-DE` οδηγεί στα γερμανικά, το `nl-NL` στα ολλανδικά και το `pt-PT` στα πορτογαλικά, επειδή αυτές οι οικογένειες τοπικών ρυθμίσεων υποστηρίζονται.

Αν καμία γλώσσα προγράμματος περιήγησης ή συσκευής δεν αντιστοιχεί σε υποστηριζόμενη τοπική ρύθμιση, οι επισκέπτες λαμβάνουν την προεπιλογή στα αγγλικά.
