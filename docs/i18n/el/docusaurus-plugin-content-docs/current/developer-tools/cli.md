# Bitsocial CLI

Το `bitsocial-cli` είναι ένα εργαλείο γραμμής εντολών για την αλληλεπίδραση με το backend του πρωτοκόλλου Bitsocial. Σας επιτρέπει να εκτελείτε έναν τοπικό daemon P2P, να δημιουργείτε και να διαμορφώνετε κοινότητες και να δημοσιεύετε περιεχόμενο -- όλα από το τερματικό.

Είναι χτισμένο πάνω στο κοινό επίπεδο πελάτη του πρωτοκόλλου Bitsocial και χρησιμοποιείται από το [5chan](/apps/5chan/) και το [Seedit](/apps/seedit/) για τη δημιουργία κοινοτήτων και τη διαχείριση κόμβων.

## Εγκατάσταση

Διατίθενται έτοιμα εκτελέσιμα αρχεία για Windows, macOS και Linux. Κατεβάστε την πιο πρόσφατη έκδοση για την πλατφόρμα σας από το GitHub:

**[Λήψη από τα GitHub Releases](https://github.com/bitsocialnet/bitsocial-cli/releases)**

Μετά τη λήψη, δώστε δικαιώματα εκτέλεσης στο αρχείο (macOS/Linux):

```bash
chmod +x bitsocial
```

## Εκτέλεση του daemon

Η πιο συνηθισμένη χρήση του CLI είναι η εκτέλεση ενός κόμβου Bitsocial. Ο daemon ξεκινά το επίπεδο δικτύωσης P2P και εκθέτει ένα τοπικό API στο οποίο μπορούν να συνδεθούν τα προγράμματα-πελάτες.

```bash
bitsocial daemon
```

Στην πρώτη εκκίνηση, ο daemon εμφανίζει συνδέσμους προς το **WebUI**, ένα γραφικό περιβάλλον μέσα στο πρόγραμμα περιήγησης για τη διαχείριση του κόμβου, των κοινοτήτων και των ρυθμίσεών σας. Είναι χρήσιμο αν προτιμάτε ένα γραφικό περιβάλλον αντί για εντολές στο τερματικό.

## Βασικές ενέργειες

| Ενέργεια                 | Περιγραφή                                                    |
| ------------------------ | ------------------------------------------------------------ |
| Εκκίνηση του daemon      | Εκκίνηση του κόμβου P2P του Bitsocial                        |
| Δημιουργία κοινότητας    | Δημιουργία μιας νέας κοινότητας                              |
| Επεξεργασία κοινότητας   | Ενημέρωση ρυθμίσεων κοινότητας (τίτλος, περιγραφή, κανόνες)  |
| Λίστα τοπικών κοινοτήτων | Εμφάνιση των κοινοτήτων που φιλοξενούνται σε αυτόν τον κόμβο |
| Εκκίνηση κοινότητας      | Έναρξη εξυπηρέτησης μιας συγκεκριμένης κοινότητας            |
| Διακοπή κοινότητας       | Παύση εξυπηρέτησης μιας συγκεκριμένης κοινότητας             |

Εκτελέστε το CLI με `--help` για να δείτε τα τρέχοντα ονόματα εντολών και τις σημαίες που εκθέτει η εγκατεστημένη έκδοσή σας:

```bash
bitsocial --help
bitsocial daemon --help
```

## Τυπική ροή εργασίας

Μια συνηθισμένη ροή ρύθμισης για τη φιλοξενία μιας νέας κοινότητας:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

Από εκεί και πέρα, χρησιμοποιήστε τις εντολές διαχείρισης κοινοτήτων της εγκατεστημένης έκδοσης για να δημιουργήσετε, να διαμορφώσετε και να ξεκινήσετε την εξυπηρέτηση μιας κοινότητας. Μόλις ξεκινήσει, η κοινότητα είναι ζωντανή στο δίκτυο Bitsocial και προσβάσιμη από συμβατά προγράμματα-πελάτες.
