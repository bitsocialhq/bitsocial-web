# EVM কন্ট্রাক্ট কল চ্যালেঞ্জ

EVM কন্ট্রাক্ট কল চ্যালেঞ্জ কোনো প্রকাশনার অনুমতি দেওয়ার আগে লেখকের অন-চেইন অবস্থা যাচাই করে। কমিউনিটির মালিকরা শর্ত দিতে পারেন যে পোস্ট করার আগে একটি ওয়ালেট বা নির্ধারিত পরিচয়কে শুধু-পঠনযোগ্য কোনো স্মার্ট-কন্ট্রাক্ট শর্ত পূরণ করতে হবে, যেমন সর্বনিম্ন একটি টোকেন ব্যালেন্স ধরে রাখা।

- **সোর্স কোড ও বর্তমান README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **npm প্যাকেজ:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## ইনস্টলেশন

```bash
npm install @bitsocial/evm-contract-challenge
```

## এটি কোথায় খাপ খায়

যেসব কমিউনিটিতে অংশগ্রহণ বাইরের কোনো EVM সংকেতের উপর নির্ভর করা উচিত, সেখানে এই চ্যালেঞ্জটি ব্যবহার করুন: টোকেনের মালিকানা, NFT-এর মালিকানা, প্রুফ-অব-পার্সনহুড স্কোর, গভর্ন্যান্স সদস্যপদ, বা কন্ট্রাক্ট থেকে পড়া যায় এমন অন্য কোনো শর্ত।

একবার কনফিগার করা হয়ে গেলে লেখকের দিক থেকে চ্যালেঞ্জটি স্বয়ংক্রিয়। এটি যোগ্য ওয়ালেট বা পরিচয়ের উৎসগুলো পরীক্ষা করে, কনফিগার করা কন্ট্রাক্ট মেথডটি কল করে, এবং ফেরত আসা মানটি কমিউনিটির শর্তের সঙ্গে মিলিয়ে দেখে।

## প্যাকেজের বর্তমান রেফারেন্স

এই পৃষ্ঠাটি ইচ্ছাকৃতভাবেই একটি সংক্ষিপ্ত পরিচিতি, হুবহু নকল করা কনফিগারেশন রেফারেন্স নয়। চ্যালেঞ্জের নাম, Bitsocial CLI-এর উদাহরণ, pkc-js রেজিস্ট্রেশন, অপশনের ডিফল্ট মান, ABI উদাহরণ, RPC আচরণ এবং সমর্থিত ওয়ালেট উৎসের জন্য প্যাকেজের README-ই সত্যের উৎস:

- [EVM কন্ট্রাক্ট চ্যালেঞ্জ README](https://github.com/bitsocialnet/evm-contract-challenge#readme)

সক্রিয় কোনো কমিউনিটি কনফিগার করার সময় আপস্ট্রিম README-কেই প্রাধান্য দিন, কারণ কন্ট্রাক্টের অপশন ও উদাহরণের সংস্করণ এই ওয়েবসাইটের সঙ্গে নয়, ওই প্যাকেজের সঙ্গে বাঁধা।

## কখন এটি ব্যবহার করবেন

EVM কন্ট্রাক্ট কল চ্যালেঞ্জ আদর্শ এসব ক্ষেত্রে:

- **টোকেন-নিয়ন্ত্রিত কমিউনিটি**, যেখানে কেবল টোকেন-হোল্ডাররাই পোস্ট করতে পারেন।
- **NFT-নিয়ন্ত্রিত অ্যাক্সেস**, যেখানে নির্দিষ্ট একটি NFT-এর মালিকানা থাকা লাগে।
- **DAO গভর্ন্যান্স স্পেস**, যেখানে অংশগ্রহণ কেবল গভর্ন্যান্স টোকেন-হোল্ডারদের মধ্যেই সীমিত।

যেসব কমিউনিটি অন-চেইন পরিচয়ের উপর নির্ভর করে না, তাদের জন্য বরং [স্প্যাম ব্লকার](./spam-blocker.md) বা [ভাউচার চ্যালেঞ্জ](./voucher-challenge.md) বিবেচনা করুন।
