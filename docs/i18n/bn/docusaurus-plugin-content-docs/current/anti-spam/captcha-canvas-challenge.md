# ক্যাপচা ক্যানভাস চ্যালেঞ্জ

ক্যাপচা ক্যানভাস চ্যালেঞ্জ হলো Bitsocial কমিউনিটির জন্য একটি স্বতন্ত্র ইমেজ ক্যাপচা প্যাকেজ। এটি একটি ক্যানভাসে এলোমেলো লেখা রেন্ডার করে এবং কমিউনিটিকে সুযোগ দেয় যাতে কোনো প্রকাশনা গ্রহণ করার আগে লেখকদের সেই ছবিটি সমাধান করতে বলা যায়।

- **সোর্স কোড ও বর্তমান README:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **npm প্যাকেজ:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## ইনস্টলেশন

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## এটি কোথায় খাপ খায়

কোনো কমিউনিটি যখন কম ঝুঁকির স্প্যাম প্রতিরোধের জন্য সহজ একটি ইন্টারঅ্যাকটিভ বাধা চায়, তখন ক্যাপচা চ্যালেঞ্জ কাজে লাগে। এই প্যাকেজটি ইচ্ছাকৃতভাবেই সীমিত পরিসরের: এটি কেবল চ্যালেঞ্জের বাস্তবায়নটুকু দেয়, আর কখন ও কীভাবে সেটি দেখানো হবে তা ঠিক করে কমিউনিটি বা Bitsocial নোড।

আরও শক্ত সুরক্ষার জন্য ক্যাপচাকে সম্পূর্ণ অ্যান্টি-স্প্যাম কৌশল হিসেবে না ধরে বরং বিস্তৃত মডারেশন বা ঝুঁকি-স্কোরিং ব্যবস্থার সঙ্গে মিলিয়ে ব্যবহার করুন।

## প্যাকেজের বর্তমান রেফারেন্স

এই পৃষ্ঠাটি ইচ্ছাকৃতভাবেই একটি সংক্ষিপ্ত পরিচিতি, হুবহু নকল করা সেটআপ গাইড নয়। বর্তমান চ্যালেঞ্জের নাম, রেজিস্ট্রেশনের উদাহরণ, CLI উদাহরণ, সমর্থিত অপশন, প্রয়োজনীয়তা এবং নিরাপত্তা-সংক্রান্ত নোটের জন্য প্যাকেজের README-ই সত্যের উৎস:

- [ক্যাপচা ক্যানভাস চ্যালেঞ্জ README](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)

সক্রিয় কোনো কমিউনিটি কনফিগার করার সময় আপস্ট্রিম README-কেই প্রাধান্য দিন, কারণ প্যাকেজের অপশন ও ইনস্টল প্রক্রিয়ার সংস্করণ এই ওয়েবসাইটের সঙ্গে নয়, ওই প্যাকেজের সঙ্গে বাঁধা।
