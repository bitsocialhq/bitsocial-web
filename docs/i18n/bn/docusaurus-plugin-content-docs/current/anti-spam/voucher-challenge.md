# ভাউচার চ্যালেঞ্জ

ভাউচার চ্যালেঞ্জ কমিউনিটির মালিকের বিতরণ করা অনন্য ভাউচার কোডের পেছনে কনটেন্ট প্রকাশ আটকে রাখে। স্বয়ংক্রিয় স্কোরিংয়ের উপর নির্ভর করার বদলে এটি আস্থার ভারটি সরিয়ে দেয় একটি ম্যানুয়াল ইনভাইট প্রক্রিয়ায়, যেখানে পরিচিত মানুষজন মালিকের নিয়ন্ত্রণে থাকা কোনো চ্যানেলের মাধ্যমে কোড পান।

- **সোর্স কোড ও বর্তমান README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **npm প্যাকেজ:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## ইনস্টলেশন

```bash
npm install @bitsocial/voucher-challenge
```

## এটি কীভাবে কাজ করে

1. কমিউনিটির মালিক এক বা একাধিক অনন্য ভাউচার কোড তৈরি করেন।
2. মালিক নিজের পছন্দের কোনো চ্যানেলের মাধ্যমে (সরাসরি বার্তা, ইমেইল, সামনাসামনি, ইত্যাদি) সেই কোডগুলো বিশ্বস্ত লেখকদের কাছে পৌঁছে দেন।
3. কোনো লেখক প্রকাশ করার চেষ্টা করলে চ্যালেঞ্জ ব্যবস্থা তাঁর কাছে একটি ভাউচার কোড চায়।
4. কোডটি যাচাই করা হয় -- সেটি আসল হলে এবং আগে ব্যবহার না হয়ে থাকলে প্রকাশনাটি গ্রহণ করা হয়।

একবার ব্যবহার হয়ে গেলে প্রতিটি ভাউচার কোড একজন নির্দিষ্ট লেখকের সঙ্গে বাঁধা পড়ে যায়, ফলে অন্য কেউ সেটি আর কাজে লাগাতে পারে না।

## প্যাকেজের বর্তমান রেফারেন্স

এই পৃষ্ঠাটি ইচ্ছাকৃতভাবেই একটি সংক্ষিপ্ত পরিচিতি, হুবহু নকল করা সেটআপ গাইড নয়। বর্তমান চ্যালেঞ্জের নাম, Bitsocial CLI-এর উদাহরণ, pkc-js রেজিস্ট্রেশন, সমর্থিত অপশন এবং কোড ব্যবহারের আচরণের জন্য প্যাকেজের README-ই সত্যের উৎস:

- [ভাউচার চ্যালেঞ্জ README](https://github.com/bitsocialnet/voucher-challenge#readme)

সক্রিয় কোনো কমিউনিটি কনফিগার করার সময় আপস্ট্রিম README-কেই প্রাধান্য দিন, কারণ ভাউচার অপশন ও ইনস্টল প্রক্রিয়ার সংস্করণ এই ওয়েবসাইটের সঙ্গে নয়, ওই প্যাকেজের সঙ্গে বাঁধা।

## কখন এটি ব্যবহার করবেন

ভাউচার চ্যালেঞ্জ সবচেয়ে উপযুক্ত এসব ক্ষেত্রে:

- **শুধু আমন্ত্রণভিত্তিক কমিউনিটি**, যেখানে সদস্যপদ ইচ্ছাকৃতভাবেই সীমিত রাখা হয়।
- **বাছাই করা স্পেস**, যেখানে মালিক নিজে প্রত্যেক অংশগ্রহণকারীকে যাচাই করেন।
- **উচ্চ-আস্থার পরিবেশ**, যেখানে স্বয়ংক্রিয় স্প্যাম স্কোরিং অপ্রয়োজনীয় বা অনাকাঙ্ক্ষিত।

ম্যানুয়ালি কোড বিতরণ করতে হয় বলে এটি বড় ও উন্মুক্ত কমিউনিটির মাপে কাজ করে না। সেসব ক্ষেত্রে বরং [স্প্যাম ব্লকার](./spam-blocker.md) বা [EVM কন্ট্রাক্ট কল চ্যালেঞ্জ](./evm-contract-call.md) বিবেচনা করুন।
