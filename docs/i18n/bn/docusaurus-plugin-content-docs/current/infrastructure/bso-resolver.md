# BSO Resolver

BSO Resolver, Bitsocial TXT রেকর্ড পড়ে `.bso` ডোমেইন নামগুলোকে তাদের সংশ্লিষ্ট পাবলিক কী-তে রূপান্তর করে। ব্যবহারকারীর চোখে পড়া কোনো `.bso` নামকে যখন পিয়ার-টু-পিয়ার স্ট্যাকের বোধগম্য কী-উপাদানে পরিণত করতে হয়, তখন Bitsocial টুলিং এই রিসলভার প্যাকেজটিই ব্যবহার করে।

- **সোর্স কোড ও বর্তমান README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **npm প্যাকেজ:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## ইনস্টলেশন

```bash
npm install @bitsocial/bso-resolver
```

## এটি কোথায় খাপ খায়

Bitsocial নামগুলো সম্প্রদায় ও লেখকদের জন্য মানুষের-পাঠযোগ্য প্রবেশপথ হিসেবে ভাবা হয়েছে। রিসলভার এই নামকরণ স্তরটিকে অ্যাপ্লিকেশন কোড থেকে আলাদা রাখে, ফলে ক্লায়েন্টরা প্রথমে জেনে নিতে পারে কোনো নাম সমর্থিত কি না, তারপর প্যাকেজের রানটাইম-নির্দিষ্ট এন্ট্রি পয়েন্টের মাধ্যমে সেটি রিসলভ করতে পারে।

কেবল কাঁচা পাবলিক কী নয়, `.bso` নামও গ্রহণ করতে হবে এমন কোনো Bitsocial-সচেতন ক্লায়েন্ট, কমান্ড-লাইন টুল বা পরিষেবা ইন্টিগ্রেট করার সময় এটি ব্যবহার করুন।
