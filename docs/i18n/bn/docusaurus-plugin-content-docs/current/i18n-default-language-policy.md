# i18n ডিফল্ট ভাষা নীতি

বেনামী দর্শকদের ক্ষেত্রে ভাষা এই ক্রম অনুসারে নির্ধারিত হয়:

1. `?lang=` কোয়েরি প্যারামিটার
2. ভাষা নির্বাচকে সংরক্ষিত পছন্দ (ব্রাউজারে `localStorage`, SSR-এর জন্য `i18nextLng` কুকিতে প্রতিফলিত)
3. ব্রাউজার বা ডিভাইসের ভাষা, যদি সেটি আমাদের সমর্থিত লোকেলগুলোর একটি হয়
4. শেষ উপায় হিসেবে `en`

সমর্থিত কোনো ব্রাউজার বা ডিভাইস ভাষাকে অগ্রাহ্য করার জন্য দেশ বা অঞ্চল ব্যবহার করা হয় না। উদাহরণস্বরূপ, `de-DE` থেকে জার্মান, `nl-NL` থেকে ডাচ এবং `pt-PT` থেকে পর্তুগিজ নির্ধারিত হয়, কারণ ওই লোকেল পরিবারগুলো সমর্থিত।

ব্রাউজার বা ডিভাইসের কোনো ভাষা যদি সমর্থিত লোকেলের সঙ্গে না মেলে, তাহলে দর্শক ইংরেজি ডিফল্ট পান।
