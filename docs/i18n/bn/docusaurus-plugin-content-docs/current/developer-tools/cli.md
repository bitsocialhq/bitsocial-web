# Bitsocial CLI

`bitsocial-cli` হলো Bitsocial প্রোটোকল ব্যাকএন্ডের সঙ্গে কাজ করার একটি কমান্ড-লাইন টুল। এটি দিয়ে আপনি একটি লোকাল P2P ডেমন চালাতে পারেন, সম্প্রদায় তৈরি ও কনফিগার করতে পারেন এবং কনটেন্ট প্রকাশ করতে পারেন -- সবই টার্মিনাল থেকে।

এটি শেয়ার করা Bitsocial প্রোটোকল ক্লায়েন্ট স্তরের উপরে তৈরি, এবং সম্প্রদায় তৈরি ও নোড ব্যবস্থাপনার জন্য [5chan](/apps/5chan/) ও [Seedit](/apps/seedit/) এটিই ব্যবহার করে।

## ইনস্টলেশন

Windows, macOS ও Linux-এর জন্য পূর্ব-নির্মিত বাইনারি পাওয়া যায়। GitHub থেকে আপনার প্ল্যাটফর্মের সর্বশেষ রিলিজ ডাউনলোড করুন:

**[GitHub Releases থেকে ডাউনলোড করুন](https://github.com/bitsocialnet/bitsocial-cli/releases)**

ডাউনলোড করার পরে বাইনারিটিকে এক্সিকিউটেবল করে নিন (macOS/Linux):

```bash
chmod +x bitsocial
```

## ডেমন চালানো

CLI-এর সবচেয়ে সাধারণ ব্যবহার হলো একটি Bitsocial নোড চালানো। ডেমনটি P2P নেটওয়ার্কিং স্তর চালু করে এবং একটি লোকাল API উন্মুক্ত করে, যাতে ক্লায়েন্টরা সংযুক্ত হতে পারে।

```bash
bitsocial daemon
```

প্রথমবার চালু করার সময় ডেমনটি **WebUI**-এর লিঙ্ক দেখায় — আপনার নোড, সম্প্রদায় ও সেটিংস পরিচালনার জন্য এটি একটি ব্রাউজার-ভিত্তিক গ্রাফিকাল ইন্টারফেস। টার্মিনাল কমান্ডের চেয়ে GUI পছন্দ করলে এটি কাজে লাগে।

## প্রধান কাজগুলো

| কাজ                            | বর্ণনা                                                 |
| ------------------------------ | ------------------------------------------------------ |
| ডেমন চালু করা                  | Bitsocial P2P নোড চালু করুন                            |
| একটি সম্প্রদায় তৈরি করা       | একটি নতুন সম্প্রদায় তৈরি করুন                         |
| একটি সম্প্রদায় সম্পাদনা করা   | সম্প্রদায়ের সেটিংস আপডেট করুন (শিরোনাম, বিবরণ, নিয়ম) |
| লোকাল সম্প্রদায়ের তালিকা দেখা | এই নোডে হোস্ট করা সম্প্রদায়ের তালিকা দেখুন            |
| একটি সম্প্রদায় চালু করা       | নির্দিষ্ট একটি সম্প্রদায় পরিবেশন করা শুরু করুন        |
| একটি সম্প্রদায় বন্ধ করা       | নির্দিষ্ট একটি সম্প্রদায় পরিবেশন করা বন্ধ করুন        |

আপনার ইনস্টল করা রিলিজে থাকা বর্তমান কমান্ডের নাম ও ফ্ল্যাগ দেখতে `--help` দিয়ে CLI চালান:

```bash
bitsocial --help
bitsocial daemon --help
```

## সাধারণ কর্মপ্রবাহ

একটি নতুন সম্প্রদায় হোস্ট করার সাধারণ সেটআপ প্রবাহ:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

সেখান থেকে, ইনস্টল করা রিলিজের সম্প্রদায়-ব্যবস্থাপনা কমান্ড ব্যবহার করে একটি সম্প্রদায় তৈরি ও কনফিগার করুন এবং পরিবেশন করা শুরু করুন। একবার চালু হলে সম্প্রদায়টি Bitsocial নেটওয়ার্কে লাইভ থাকে এবং সামঞ্জস্যপূর্ণ ক্লায়েন্ট থেকে অ্যাক্সেস করা যায়।
