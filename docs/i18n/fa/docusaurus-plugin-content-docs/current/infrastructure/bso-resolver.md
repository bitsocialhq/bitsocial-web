# BSO Resolver

BSO Resolver با خواندن رکوردهای TXT در Bitsocial، نام‌های دامنه `.bso` را به کلیدهای عمومی متناظرشان برمی‌گرداند. این همان بسته حل‌کننده‌ای است که ابزارهای Bitsocial زمانی از آن استفاده می‌کنند که یک نام `.bso` در سطح کاربر باید به همان داده کلیدی تبدیل شود که پشته همتا به همتا آن را می‌فهمد.

- **کد منبع و README فعلی:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **بسته npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## نصب

```bash
npm install @bitsocial/bso-resolver
```

## جایگاه آن در معماری

قرار است نام‌های Bitsocial نقطه ورود خوانا برای آدم‌ها به انجمن‌ها و نویسندگان باشند. حل‌کننده این لایه نام‌گذاری را از کد اپلیکیشن جدا نگه می‌دارد، تا کلاینت‌ها بتوانند اول بپرسند آیا یک نام پشتیبانی می‌شود و بعد آن را از طریق نقطه ورودِ مخصوص همان محیط اجرا در بسته حل کنند.

هر وقت کلاینت، ابزار خط فرمان یا سرویسی می‌سازید که باید به‌جای کلیدهای عمومی خام، نام‌های `.bso` را هم بپذیرد، از آن استفاده کنید.
