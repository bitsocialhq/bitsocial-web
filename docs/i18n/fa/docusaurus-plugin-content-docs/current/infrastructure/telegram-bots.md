# ربات‌های Telegram

ربات‌های Telegram در Bitsocial فهرست انجمن‌های کلاینت‌ها را روی شبکه Bitsocial رصد می‌کنند و پست‌های تازه را به‌طور خودکار به کانال‌های Telegram بازارسال می‌کنند. هر پیام بازارسال‌شده دکمه‌های درون‌خطی دارد که به پست اصلی در 5chan و Seedit پیوند می‌خورند.

- **GitHub**: [bitsocialnet/bitsocial-telegram-bots](https://github.com/bitsocialnet/bitsocial-telegram-bots)

## ربات‌های موجود

| ربات           | وضعیت           | توضیح                                                                         |
| -------------- | --------------- | ----------------------------------------------------------------------------- |
| **فید 5chan**  | فعال            | همه دایرکتوری‌های 5chan را رصد می‌کند و پست‌های تازه را به Telegram می‌فرستد. |
| **فید Seedit** | برنامه‌ریزی‌شده | همین قابلیت را برای انجمن‌های Seedit فراهم خواهد کرد.                         |

## راه‌اندازی

### پیش‌نیازها

- Node.js
- Yarn
- یک توکن ربات Telegram (یکی را از راه [BotFather](https://t.me/BotFather) بسازید)

### نصب

مخزن را کلون کنید و وابستگی‌ها را نصب کنید:

```bash
git clone https://github.com/bitsocialnet/bitsocial-telegram-bots.git
cd bitsocial-telegram-bots
yarn install
```

### پیکربندی

یک فایل `.env` در ریشه پروژه بسازید و توکن ربات خود را در آن بگذارید:

```env
BOT_TOKEN=your_telegram_bot_token
```

### اجرا

پس از پیکربندی محیط، ربات را راه بیندازید:

```bash
yarn start
```

## قالب پست

وقتی ربات یک پست را به Telegram بازارسال می‌کند، دو دکمه درون‌خطی هم همراهش می‌آید:

- **مشاهده در 5chan** — پست را در کلاینت وب 5chan باز می‌کند.
- **مشاهده در Seedit** — پست را در کلاینت وب Seedit باز می‌کند.

این کار به مشترکان Telegram اجازه می‌دهد مستقیم سراغ رشته کامل بحث بروند، در هر کلاینتی که ترجیح می‌دهند.
