# Bitsocial CLI

`bitsocial-cli` یک ابزار خط فرمان برای کار با بخش پشتیبان پروتکل Bitsocial است. با آن می‌توانید یک دیمون محلی P2P را اجرا کنید، انجمن بسازید و پیکربندی کنید، و محتوا منتشر کنید — همه از داخل ترمینال.

این ابزار روی لایه مشترک کلاینت پروتکل Bitsocial ساخته شده و [5chan](/apps/5chan/) و [Seedit](/apps/seedit/) برای ساخت انجمن و مدیریت گره از آن استفاده می‌کنند.

## نصب

باینری‌های از پیش ساخته‌شده برای Windows، macOS و Linux در دسترس‌اند. آخرین نسخه مناسب پلتفرم خود را از GitHub دانلود کنید:

**[دانلود از GitHub Releases](https://github.com/bitsocialnet/bitsocial-cli/releases)**

پس از دانلود، باینری را اجراپذیر کنید (macOS/Linux):

```bash
chmod +x bitsocial
```

## اجرای دیمون

رایج‌ترین کاربرد CLI اجرای یک گره Bitsocial است. دیمون لایه شبکه‌سازی P2P را بالا می‌آورد و یک API محلی در اختیار می‌گذارد که کلاینت‌ها می‌توانند به آن وصل شوند.

```bash
bitsocial daemon
```

در نخستین اجرا، دیمون پیوندهایی به **WebUI** چاپ می‌کند؛ یک رابط گرافیکی مبتنی بر مرورگر برای مدیریت گره، انجمن‌ها و تنظیمات شما. اگر رابط گرافیکی را به دستورهای ترمینال ترجیح می‌دهید، این به کارتان می‌آید.

## کارهای اصلی

| کار                  | توضیح                                            |
| -------------------- | ------------------------------------------------ |
| اجرای دیمون          | بالا آوردن گره P2P مربوط به Bitsocial            |
| ساخت یک انجمن        | ساختن یک انجمن تازه                              |
| ویرایش یک انجمن      | به‌روزرسانی تنظیمات انجمن (عنوان، توضیح، قوانین) |
| فهرست انجمن‌های محلی | فهرست انجمن‌هایی که روی این گره میزبانی می‌شوند  |
| شروع یک انجمن        | آغاز ارائه یک انجمن مشخص                         |
| توقف یک انجمن        | توقف ارائه یک انجمن مشخص                         |

برای دیدن نام دستورها و پرچم‌هایی که نسخه نصب‌شده شما در اختیار می‌گذارد، CLI را با `--help` اجرا کنید:

```bash
bitsocial --help
bitsocial daemon --help
```

## گردش کار معمول

یک جریان راه‌اندازی رایج برای میزبانی یک انجمن تازه:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

از آنجا به بعد، با دستورهای مدیریت انجمن در نسخه نصب‌شده، انجمن را بسازید، پیکربندی کنید و ارائه آن را آغاز کنید. پس از شروع، انجمن روی شبکه Bitsocial زنده است و از کلاینت‌های سازگار در دسترس قرار می‌گیرد.
