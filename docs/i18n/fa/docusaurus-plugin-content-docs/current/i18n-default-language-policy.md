# سیاست زبان پیش‌فرض i18n

برای بازدیدکنندگان ناشناس، زبان به این ترتیب تعیین می‌شود:

1. پارامتر کوئری `?lang=`
2. انتخاب ذخیره‌شده در گزینشگر زبان (`localStorage` در مرورگر، که برای SSR در کوکی `i18nextLng` نیز بازتاب می‌یابد)
3. زبان مرورگر یا دستگاه، در صورتی که یکی از زبان‌های پشتیبانی‌شده باشد
4. بازگشت به `en`

کشور یا منطقه برای نادیده‌گرفتن زبانِ پشتیبانی‌شدهٔ مرورگر یا دستگاه به کار نمی‌رود. برای نمونه، `de-DE` به آلمانی، `nl-NL` به هلندی و `pt-PT` به پرتغالی می‌انجامد، چون این خانواده‌های زبانی پشتیبانی می‌شوند.

اگر هیچ زبان مرورگر یا دستگاهی با زبان‌های پشتیبانی‌شده مطابقت نداشته باشد، بازدیدکننده نسخهٔ پیش‌فرض انگلیسی را دریافت می‌کند.
