# چالش کپچای Canvas

چالش کپچای Canvas یک بسته‌ی مستقل کپچای تصویری برای جوامع Bitsocial است. متنی تصادفی را روی یک canvas ترسیم می‌کند و به یک جامعه امکان می‌دهد پیش از پذیرفتن یک انتشار، از نویسنده بخواهد تصویر را حل کند.

- **کد منبع و README فعلی:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **بسته‌ی npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## نصب

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## کجا به کار می‌آید

چالش‌های کپچا وقتی مفیدند که یک جامعه دروازه‌ای تعاملی و ساده برای مقاومت در برابر اسپم کم‌خطر بخواهد. این بسته عمداً محدود است: تنها پیاده‌سازی چالش را فراهم می‌کند، و اینکه چه زمانی و چگونه نمایش داده شود بر عهده‌ی جامعه یا گره Bitsocial است.

برای محافظت قوی‌تر، به‌جای آنکه کپچا را یک راهبرد کامل ضد اسپم بدانید، آن را با سامانه‌های گسترده‌تر نظارت بر محتوا یا امتیازدهی ریسک ترکیب کنید.
