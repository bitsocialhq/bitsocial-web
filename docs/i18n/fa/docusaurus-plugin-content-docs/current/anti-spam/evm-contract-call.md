# چالش فراخوانی قرارداد EVM

چالش فراخوانی قرارداد EVM پیش از آنکه اجازه‌ی انتشار بدهد، وضعیت نویسنده را روی زنجیره بررسی می‌کند. مالکان جامعه می‌توانند شرط کنند که یک کیف پول یا هویت شناسایی‌شده پیش از ارسال مطلب، شرطی فقط‌خواندنی در یک قرارداد هوشمند را برآورده کند، مثلاً داشتن حداقلی از موجودی توکن.

- **کد منبع و README فعلی:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **بسته‌ی npm:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## نصب

```bash
npm install @bitsocial/evm-contract-challenge
```

## کجا به کار می‌آید

از این چالش در جوامعی استفاده کنید که مشارکت در آن‌ها باید به یک سیگنال بیرونی روی EVM وابسته باشد: مالکیت توکن، مالکیت NFT، امتیازهای اثبات انسان بودن، عضویت در حکمرانی، یا هر شرط دیگری که از روی قرارداد قابل خواندن باشد.

پس از پیکربندی، این چالش از دید نویسنده خودکار است. منابع کیف پول یا هویت واجد شرایط را بررسی می‌کند، متد پیکربندی‌شده‌ی قرارداد را فراخوانی می‌کند و مقدار بازگشتی را با شرط جامعه مقایسه می‌کند.

## مرجع فعلی بسته

این صفحه عمداً یک مرور کلی است، نه بازتابی از مرجع پیکربندی. README بسته منبع حقیقت برای نام‌های چالش‌ها، نمونه‌های Bitsocial CLI، ثبت در pkc-js، مقادیر پیش‌فرض گزینه‌ها، نمونه‌های ABI، رفتار RPC و منابع کیف پول پشتیبانی‌شده است:

- [README مربوط به EVM Contract Challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)

هنگام پیکربندی یک جامعه‌ی زنده، README بالادستی را ترجیح دهید، چون گزینه‌ها و نمونه‌های قرارداد همراه با خود آن بسته نسخه‌بندی می‌شوند، نه همراه با این وب‌سایت.

## چه زمانی از آن استفاده کنیم

چالش فراخوانی قرارداد EVM برای این موارد ایده‌آل است:

- **جوامع دروازه‌بندی‌شده با توکن** که ارسال مطلب را به دارندگان توکن محدود می‌کنند.
- **دسترسی دروازه‌بندی‌شده با NFT** که در آن مالکیت یک NFT مشخص لازم است.
- **فضاهای حکمرانی DAO** که مشارکت در آن‌ها به دارندگان توکن حکمرانی محدود است.

برای جوامعی که به هویت روی زنجیره متکی نیستند، به‌جای این گزینه [مسدود کننده اسپم](./spam-blocker.md) یا [چالش ووچر](./voucher-challenge.md) را در نظر بگیرید.
