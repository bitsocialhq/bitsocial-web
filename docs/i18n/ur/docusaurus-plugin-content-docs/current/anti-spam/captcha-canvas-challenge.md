# Captcha Canvas Challenge

Captcha Canvas Challenge، Bitsocial کمیونٹیز کے لیے ایک خودمختار امیج کیپچا پیکیج ہے۔ یہ بے ترتیب متن کو کینوس پر رینڈر کرتا ہے اور کمیونٹی کو یہ سہولت دیتا ہے کہ اشاعت قبول کرنے سے پہلے مصنف سے وہ تصویر حل کروا لے۔

- **ماخذ کوڈ اور موجودہ README:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **npm پیکیج:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## انسٹالیشن

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## یہ کہاں فٹ ہوتا ہے

کیپچا چیلنجز اُس وقت کارآمد ہیں جب کوئی کمیونٹی کم خطرے والے سپیم کے خلاف ایک سادہ، انٹرایکٹو رکاوٹ چاہتی ہو۔ یہ پیکیج جان بوجھ کر محدود دائرے کا ہے: یہ صرف چیلنج کا نفاذ فراہم کرتا ہے، جبکہ یہ فیصلہ کمیونٹی یا Bitsocial نوڈ کرتا ہے کہ اسے کب اور کیسے پیش کیا جائے۔

زیادہ مضبوط تحفظ کے لیے کیپچا کو مکمل اینٹی سپیم حکمتِ عملی سمجھنے کے بجائے اسے وسیع تر ماڈریشن یا رسک اسکورنگ نظاموں کے ساتھ ملا کر استعمال کریں۔

## موجودہ پیکیج کا حوالہ

یہ صفحہ جان بوجھ کر ایک جائزہ ہے، سیٹ اپ گائیڈ کی نقل نہیں۔ موجودہ چیلنج ناموں، رجسٹریشن کی مثالوں، CLI مثالوں، دستیاب آپشنز، تقاضوں اور سیکیورٹی نوٹس کے لیے پیکیج کا README ہی معتبر ماخذ ہے:

- [Captcha Canvas Challenge README](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
