# Voucher Challenge

Voucher Challenge مواد کی اشاعت کو کمیونٹی کے مالک کی تقسیم کردہ منفرد واؤچر کوڈز کے پیچھے محدود رکھتا ہے۔ خودکار اسکورنگ پر انحصار کرنے کے بجائے یہ بھروسے کو ایک دستی دعوتی طریقے پر منتقل کر دیتا ہے، جہاں جانے پہچانے لوگوں کو کوڈ ایسے ذریعے سے ملتے ہیں جو مالک کے اپنے کنٹرول میں ہے۔

- **ماخذ کوڈ اور موجودہ README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **npm پیکیج:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## انسٹالیشن

```bash
npm install @bitsocial/voucher-challenge
```

## یہ کیسے کام کرتا ہے

1. کمیونٹی کا مالک ایک یا زیادہ منفرد واؤچر کوڈ بناتا ہے۔
2. مالک یہ کوڈ اپنی پسند کے کسی ذریعے (ڈائریکٹ میسج، ای میل، بالمشافہ وغیرہ) قابلِ اعتماد مصنفین تک پہنچاتا ہے۔
3. جب کوئی مصنف اشاعت کی کوشش کرتا ہے، تو چیلنج سسٹم اس سے واؤچر کوڈ طلب کرتا ہے۔
4. کوڈ کی تصدیق کی جاتی ہے — اگر وہ اصلی ہے اور پہلے استعمال نہیں ہوا، تو اشاعت قبول کر لی جاتی ہے۔

ہر واؤچر کوڈ استعمال ہونے کے بعد ایک مخصوص مصنف سے منسلک ہو جاتا ہے، جس سے دوسروں کے ہاتھوں اس کا دوبارہ استعمال رک جاتا ہے۔

## موجودہ پیکیج کا حوالہ

یہ صفحہ جان بوجھ کر ایک جائزہ ہے، سیٹ اپ گائیڈ کی نقل نہیں۔ موجودہ چیلنج ناموں، Bitsocial CLI مثالوں، pkc-js رجسٹریشن، دستیاب آپشنز اور کوڈ بھنانے کے رویے کے لیے پیکیج کا README ہی معتبر ماخذ ہے:

- [Voucher Challenge README](https://github.com/bitsocialnet/voucher-challenge#readme)

کسی زندہ کمیونٹی کو ترتیب دیتے وقت اپ اسٹریم README کو ترجیح دیں، کیونکہ واؤچر کے آپشنز اور انسٹال کے طریقے اس ویب سائٹ کے بجائے اسی پیکیج کے ساتھ ورژن کیے جاتے ہیں۔

## اسے کب استعمال کریں

Voucher Challenge ان حالات کے لیے سب سے موزوں ہے:

- **صرف دعوت پر مبنی کمیونٹیز** جہاں رکنیت جان بوجھ کر محدود رکھی جاتی ہے۔
- **منتخب جگہیں** جہاں مالک ہر شریک کو خود جانچتا ہے۔
- **اعلیٰ بھروسے والے ماحول** جہاں خودکار سپیم اسکورنگ غیر ضروری یا ناپسندیدہ ہو۔

چونکہ اس میں کوڈ دستی طور پر تقسیم کرنے پڑتے ہیں، یہ بڑی کھلی کمیونٹیز کے لیے قابلِ توسیع نہیں۔ ایسے حالات کے لیے [Spam Blocker](./spam-blocker.md) یا [EVM Contract Call Challenge](./evm-contract-call.md) پر غور کریں۔
