# EVM Contract Call Challenge

EVM Contract Call Challenge کسی اشاعت کی اجازت دینے سے پہلے مصنف کی آن چین حالت کی تصدیق کرتا ہے۔ کمیونٹی کے مالکان یہ شرط رکھ سکتے ہیں کہ پوسٹ کرنے سے پہلے کوئی والٹ یا حل شدہ شناخت صرف پڑھنے والی کسی اسمارٹ کنٹریکٹ شرط کو پورا کرے، مثلاً کم از کم مقررہ ٹوکن بیلنس رکھنا۔

- **ماخذ کوڈ اور موجودہ README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **npm پیکیج:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## انسٹالیشن

```bash
npm install @bitsocial/evm-contract-challenge
```

## یہ کہاں فٹ ہوتا ہے

یہ چیلنج ایسی کمیونٹیز کے لیے استعمال کریں جہاں شرکت کا انحصار کسی بیرونی EVM اشارے پر ہونا چاہیے: ٹوکن کی ملکیت، NFT کی ملکیت، پروف آف پرسن ہُڈ اسکور، گورننس کی رکنیت، یا کوئی اور ایسی شرط جو کنٹریکٹ سے پڑھی جا سکتی ہو۔

ایک بار ترتیب دینے کے بعد یہ چیلنج مصنف کے لیے خودکار ہوتا ہے۔ یہ اہل والٹ یا شناخت کے ذرائع جانچتا ہے، مقررہ کنٹریکٹ میتھڈ کو کال کرتا ہے، اور واپس آنے والی قدر کا کمیونٹی کی شرط سے موازنہ کرتا ہے۔

## موجودہ پیکیج کا حوالہ

یہ صفحہ جان بوجھ کر ایک جائزہ ہے، کنفیگریشن ریفرنس کی نقل نہیں۔ چیلنج ناموں، Bitsocial CLI مثالوں، pkc-js رجسٹریشن، آپشنز کے ڈیفالٹس، ABI مثالوں، RPC رویے اور دستیاب والٹ ذرائع کے لیے پیکیج کا README ہی معتبر ماخذ ہے:

- [EVM Contract Challenge README](https://github.com/bitsocialnet/evm-contract-challenge#readme)

کسی زندہ کمیونٹی کو ترتیب دیتے وقت اپ اسٹریم README کو ترجیح دیں، کیونکہ کنٹریکٹ کے آپشنز اور مثالیں اس ویب سائٹ کے بجائے اسی پیکیج کے ساتھ ورژن کی جاتی ہیں۔

## اسے کب استعمال کریں

EVM Contract Call Challenge ان کے لیے بہترین ہے:

- **ٹوکن گیٹڈ کمیونٹیز** جو پوسٹ کرنے کی اجازت صرف ٹوکن ہولڈرز تک محدود رکھتی ہیں۔
- **NFT گیٹڈ رسائی** جہاں کسی مخصوص NFT کی ملکیت لازمی ہو۔
- **DAO گورننس کی جگہیں** جہاں شرکت صرف گورننس ٹوکن رکھنے والوں تک محدود ہو۔

ایسی کمیونٹیز کے لیے جو آن چین شناخت پر انحصار نہیں کرتیں، اس کے بجائے [Spam Blocker](./spam-blocker.md) یا [Voucher Challenge](./voucher-challenge.md) پر غور کریں۔
