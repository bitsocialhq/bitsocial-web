# i18n ڈیفالٹ زبان پالیسی

گمنام زائرین کے لیے زبان اسی ترتیب سے طے ہوتی ہے:

1. `?lang=` کوئری پیرامیٹر
2. زبان کے سلیکٹر میں محفوظ کیا گیا انتخاب (براؤزر میں `localStorage`، جو SSR کے لیے `i18nextLng` کوکی میں بھی نقل ہوتا ہے)
3. براؤزر یا ڈیوائس کی زبان، بشرطیکہ وہ ہمارے تعاون یافتہ لوکیلز میں سے ایک ہو
4. آخری صورت میں `en` پر واپسی

ملک یا خطے کی بنیاد پر کسی تعاون یافتہ براؤزر/ڈیوائس زبان کو تبدیل نہیں کیا جاتا۔ مثال کے طور پر، `de-DE` جرمن پر، `nl-NL` ڈچ پر، اور `pt-PT` پرتگالی پر طے ہوتی ہے، کیونکہ یہ لوکیل فیملیز تعاون یافتہ ہیں۔

اگر براؤزر یا ڈیوائس کی کوئی بھی زبان کسی تعاون یافتہ لوکیل سے میل نہ کھائے، تو زائرین کو انگریزی ڈیفالٹ ملتی ہے۔
