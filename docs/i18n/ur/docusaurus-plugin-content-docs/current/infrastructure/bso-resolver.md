# BSO ریزولور

BSO Resolver، Bitsocial TXT ریکارڈز پڑھ کر `.bso` ڈومین ناموں کو ان کی متعلقہ عوامی کلیدوں میں تبدیل کرتا ہے۔ جب صارف کو نظر آنے والے کسی `.bso` نام کو اُس کلیدی مواد میں بدلنا ہو جسے پیئر ٹو پیئر اسٹیک سمجھتا ہے، تو Bitsocial کی ٹولنگ یہی ریزولور پیکج استعمال کرتی ہے۔

- **سورس کوڈ اور موجودہ README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **npm پیکج:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## تنصیب

```bash
npm install @bitsocial/bso-resolver
```

## یہ کہاں فٹ ہوتا ہے

Bitsocial کے نام اس لیے بنائے گئے ہیں کہ وہ کمیونٹیز اور مصنفین کے لیے انسان کے پڑھنے کے قابل داخلی مقامات ہوں۔ ریزولور اس نام کاری کی پرت کو ایپلیکیشن کوڈ سے الگ رکھتا ہے، تاکہ کلائنٹس پہلے پوچھ سکیں کہ کوئی نام معاون ہے یا نہیں اور پھر اسے پیکج کے رن ٹائم کے مطابق داخلی مقام کے ذریعے حل کر سکیں۔

اسے تب استعمال کریں جب آپ کوئی Bitsocial سے واقف کلائنٹ، کمانڈ لائن ٹول، یا سروس بنا رہے ہوں جسے صرف خام عوامی کلیدوں کے بجائے `.bso` نام بھی قبول کرنے ہوں۔

## موجودہ پیکج حوالہ

یہ صفحہ جان بوجھ کر ایک جائزہ ہے، نقل شدہ API حوالہ نہیں۔ کنسٹرکٹر آپشنز، واپسی کی اقسام، کیشنگ کے رویّے، داخلی مقامات، فراہم کنندہ کی مثالوں، اور معاون شٹ ڈاؤن سیمینٹکس کے لیے پیکج کا README ہی مستند ماخذ ہے:

- [BSO Resolver README](https://github.com/bitsocialnet/bso-resolver#readme)

پروجیکٹ میں کوڈ نقل کرتے وقت اپ اسٹریم README کو ترجیح دیں، کیونکہ ریزولور کا رویّہ اس ویب سائٹ کے بجائے اُسی پیکج کے ورژن کے ساتھ بدلتا ہے۔
