# Bitsocial CLI

`bitsocial-cli` ایک کمانڈ لائن ٹول ہے جو Bitsocial پروٹوکول کے بیک اینڈ سے تعامل کرتا ہے۔ یہ آپ کو مقامی P2P ڈیمن چلانے، کمیونٹیز بنانے اور ترتیب دینے، اور مواد شائع کرنے دیتا ہے -- سب کچھ ٹرمینل سے۔

یہ Bitsocial کے مشترکہ پروٹوکول کلائنٹ پرت پر بنایا گیا ہے اور [5chan](/apps/5chan/) اور [Seedit](/apps/seedit/) اسے کمیونٹی بنانے اور نوڈ کے انتظام کے لیے استعمال کرتے ہیں۔

## تنصیب

پہلے سے تیار بائنریز Windows، macOS اور Linux کے لیے دستیاب ہیں۔ اپنے پلیٹ فارم کے لیے تازہ ترین ریلیز GitHub سے ڈاؤن لوڈ کریں:

**[GitHub ریلیزز سے ڈاؤن لوڈ کریں](https://github.com/bitsocialnet/bitsocial-cli/releases)**

ڈاؤن لوڈ کے بعد بائنری کو قابلِ عمل بنائیں (macOS/Linux):

```bash
chmod +x bitsocial
```

## ڈیمن چلانا

CLI کا سب سے عام استعمال Bitsocial نوڈ چلانا ہے۔ ڈیمن P2P نیٹ ورکنگ پرت شروع کرتا ہے اور ایک مقامی API ظاہر کرتا ہے جس سے کلائنٹس جڑ سکتے ہیں۔

```bash
bitsocial daemon
```

پہلی بار چلانے پر ڈیمن **WebUI** کے لنکس دکھاتا ہے، جو براؤزر پر مبنی ایک گرافیکل انٹرفیس ہے اور اس سے آپ اپنے نوڈ، کمیونٹیز اور ترتیبات کا انتظام کر سکتے ہیں۔ اگر آپ ٹرمینل کمانڈز کے بجائے GUI پسند کرتے ہیں تو یہ کارآمد ہے۔

## اہم کارروائیاں

| کارروائی                       | تفصیل                                          |
| ------------------------------ | ---------------------------------------------- |
| ڈیمن شروع کریں                 | Bitsocial کا P2P نوڈ چالو کریں                 |
| کمیونٹی بنائیں                 | نئی کمیونٹی بنائیں                             |
| کمیونٹی میں ترمیم کریں         | کمیونٹی کی ترتیبات بدلیں (عنوان، تفصیل، قواعد) |
| مقامی کمیونٹیز کی فہرست دیکھیں | اس نوڈ پر میزبان کمیونٹیز کی فہرست دیکھیں      |
| کمیونٹی شروع کریں              | کسی مخصوص کمیونٹی کو پیش کرنا شروع کریں        |
| کمیونٹی روکیں                  | کسی مخصوص کمیونٹی کو پیش کرنا بند کریں         |

اپنی انسٹال شدہ ریلیز میں موجود کمانڈ ناموں اور فلیگز دیکھنے کے لیے CLI کو `--help` کے ساتھ چلائیں:

```bash
bitsocial --help
bitsocial daemon --help
```

## عام ورک فلو

نئی کمیونٹی کی میزبانی کے لیے ایک عام سیٹ اپ کا طریقہ:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

اس کے بعد اپنی انسٹال شدہ ریلیز کی کمیونٹی انتظام کمانڈز استعمال کرتے ہوئے کمیونٹی بنائیں، ترتیب دیں، اور اسے پیش کرنا شروع کریں۔ ایک بار شروع ہو جانے کے بعد کمیونٹی Bitsocial نیٹ ورک پر زندہ ہوتی ہے اور موافق کلائنٹس سے قابلِ رسائی ہوتی ہے۔
