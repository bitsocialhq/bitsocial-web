# BSO रिझॉल्व्हर

BSO Resolver हे Bitsocial TXT रेकॉर्ड वाचून `.bso` डोमेन नावांचे रूपांतर त्यांच्याशी संबंधित पब्लिक कीमध्ये करते. वापरकर्त्यासमोर दिसणाऱ्या `.bso` नावाचे रूपांतर पीअर-टू-पीअर स्टॅकला समजणाऱ्या की-मटेरियलमध्ये करावे लागते तेव्हा Bitsocial साधने हेच रिझॉल्व्हर पॅकेज वापरतात.

- **सोर्स कोड आणि सध्याचे README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **npm पॅकेज:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## स्थापना

```bash
npm install @bitsocial/bso-resolver
```

## याचे स्थान कुठे आहे

Bitsocial नावे ही समुदाय आणि लेखकांसाठीची माणसाला वाचता येणारी प्रवेशद्वारे असावीत, असा हेतू आहे. रिझॉल्व्हर हा नामकरणाचा स्तर ॲप्लिकेशन कोडपासून वेगळा ठेवते, त्यामुळे क्लायंट आधी एखादे नाव समर्थित आहे का हे विचारू शकतात आणि नंतर पॅकेजच्या रनटाइम-विशिष्ट एंट्री पॉइंटमधून ते रिझॉल्व्ह करू शकतात.

तुम्ही केवळ कच्च्या पब्लिक कीऐवजी `.bso` नावेही स्वीकारणारा Bitsocial-सुसंगत क्लायंट, कमांड-लाइन साधन किंवा सेवा जोडत असाल, तेव्हा याचा वापर करा.

## सध्याचा पॅकेज संदर्भ

हे पान मुद्दामच आढावा आहे, आरशासारखा API संदर्भ नाही. कन्स्ट्रक्टर पर्याय, रिटर्न प्रकार, कॅशिंग वर्तन, एंट्री पॉइंट, प्रदात्यांची उदाहरणे आणि समर्थित शटडाउन सिमॅंटिक्स यांसाठी पॅकेजचे README हेच सत्याचे स्रोत आहे:

- [BSO Resolver README](https://github.com/bitsocialnet/bso-resolver#readme)

प्रकल्पात कोड कॉपी करताना अपस्ट्रीम README ला प्राधान्य द्या, कारण रिझॉल्व्हरचे वर्तन या वेबसाइटसोबत नव्हे तर त्या पॅकेजसोबत आवृत्तीबद्ध केले जाते.
