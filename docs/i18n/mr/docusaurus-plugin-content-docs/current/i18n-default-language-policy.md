# i18n डीफॉल्ट भाषा धोरण

अनामिक अभ्यागतांसाठी भाषा या क्रमाने ठरवली जाते:

1. `?lang=` क्वेरी पॅरामीटर
2. भाषा निवडकातून जतन केलेली निवड (ब्राउझरमध्ये `localStorage`, आणि SSR साठी `i18nextLng` कुकीमध्ये प्रतिबिंबित केलेली)
3. ब्राउझर/डिव्हाइसची भाषा, जेव्हा ती आम्ही समर्थित केलेल्या लोकेलपैकी एक असते
4. यापैकी काहीच नसल्यास `en` वर परत जाणे

समर्थित ब्राउझर/डिव्हाइस भाषेला ओव्हरराइड करण्यासाठी देश किंवा प्रदेश वापरला जात नाही. उदाहरणार्थ, `de-DE` साठी जर्मन, `nl-NL` साठी डच आणि `pt-PT` साठी पोर्तुगीज निवडली जाते, कारण त्या लोकेल कुटुंबांना समर्थन आहे.

जर कोणतीही ब्राउझर/डिव्हाइस भाषा समर्थित लोकेलशी जुळत नसेल, तर अभ्यागतांना इंग्रजी डीफॉल्ट मिळते.
