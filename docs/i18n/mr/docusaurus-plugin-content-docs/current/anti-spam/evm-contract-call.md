# EVM कॉन्ट्रॅक्ट कॉल आव्हान

EVM कॉन्ट्रॅक्ट कॉल आव्हान प्रकाशनाला परवानगी देण्यापूर्वी लेखकाची ऑन-चेन स्थिती पडताळते. समुदाय मालक पोस्ट करण्याआधी वॉलेट किंवा निश्चित झालेल्या ओळखीने फक्त-वाचन स्मार्ट-कॉन्ट्रॅक्ट अट पूर्ण करणे बंधनकारक करू शकतात — उदाहरणार्थ किमान टोकन शिल्लक बाळगणे.

- **स्रोत कोड आणि सध्याचे README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **npm पॅकेज:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## इन्स्टॉलेशन

```bash
npm install @bitsocial/evm-contract-challenge
```

## हे कुठे बसते

ज्या समुदायांमध्ये सहभाग बाह्य EVM संकेतावर अवलंबून असावा, तिथे हे आव्हान वापरा: टोकनची मालकी, NFT ची मालकी, प्रूफ-ऑफ-पर्सनहूड गुण, गव्हर्नन्स सदस्यत्व किंवा कॉन्ट्रॅक्टमधून वाचता येणारी दुसरी कोणतीही अट.

एकदा कॉन्फिगर केल्यावर लेखकाच्या दृष्टीने हे आव्हान आपोआप चालते. ते पात्र वॉलेट किंवा ओळखीचे स्रोत तपासते, कॉन्फिगर केलेली कॉन्ट्रॅक्ट मेथड कॉल करते आणि परत आलेल्या मूल्याची समुदायाच्या अटीशी तुलना करते.

## सध्याचा पॅकेज संदर्भ

हे पान मुद्दामच फक्त एक आढावा आहे, कॉन्फिगरेशन संदर्भाची प्रत नाही. आव्हान नावे, Bitsocial CLI उदाहरणे, pkc-js नोंदणी, पर्यायांची डीफॉल्ट मूल्ये, ABI उदाहरणे, RPC वर्तन आणि समर्थित वॉलेट स्रोत यांसाठी पॅकेजचे README हेच अधिकृत स्रोत आहे:

- [EVM कॉन्ट्रॅक्ट आव्हान README](https://github.com/bitsocialnet/evm-contract-challenge#readme)

थेट चालू असलेला समुदाय कॉन्फिगर करताना अपस्ट्रीम README ला प्राधान्य द्या, कारण कॉन्ट्रॅक्टचे पर्याय आणि उदाहरणे या संकेतस्थळासोबत नव्हे तर त्या पॅकेजसोबत आवृत्तीबद्ध केली जातात.

## ते कधी वापरावे

EVM कॉन्ट्रॅक्ट कॉल आव्हान यांसाठी आदर्श आहे:

- **टोकन-आधारित प्रवेश असलेले समुदाय**, जिथे फक्त टोकनधारकांनाच पोस्ट करता येते.
- **NFT-आधारित प्रवेश**, जिथे विशिष्ट NFT ची मालकी आवश्यक असते.
- **DAO गव्हर्नन्स जागा**, जिथे सहभाग फक्त गव्हर्नन्स टोकनधारकांपुरता मर्यादित असतो.

जे समुदाय ऑन-चेन ओळखीवर अवलंबून नाहीत, त्यांच्यासाठी त्याऐवजी [स्पॅम ब्लॉकर](./spam-blocker.md) किंवा [व्हाउचर आव्हान](./voucher-challenge.md) यांचा विचार करा.
