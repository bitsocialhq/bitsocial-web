# व्हाउचर आव्हान

व्हाउचर आव्हान समुदाय मालकाने वाटलेल्या अनन्य व्हाउचर कोडमागे सामग्रीचे प्रकाशन बंदिस्त करते. स्वयंचलित स्कोअरिंगवर अवलंबून राहण्याऐवजी ते विश्वासाचा भार मॅन्युअल आमंत्रण प्रवाहावर टाकते, जिथे ओळखीच्या व्यक्तींना मालकाच्या नियंत्रणातील मार्गाने कोड मिळतात.

- **स्रोत कोड आणि सध्याचे README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **npm पॅकेज:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## इन्स्टॉलेशन

```bash
npm install @bitsocial/voucher-challenge
```

## हे कसे काम करते

1. समुदाय मालक एक किंवा अधिक अनन्य व्हाउचर कोड तयार करतो.
2. मालक ते कोड आपल्या पसंतीच्या मार्गाने (डायरेक्ट मेसेज, ईमेल, प्रत्यक्ष भेट इत्यादी) विश्वासू लेखकांना वाटतो.
3. लेखक प्रकाशित करण्याचा प्रयत्न करतो, तेव्हा आव्हान प्रणाली त्याला व्हाउचर कोड विचारते.
4. कोडची पडताळणी होते -- तो खरा असेल आणि आधी वापरलेला नसेल, तर प्रकाशन स्वीकारले जाते.

एकदा वापरल्यानंतर प्रत्येक व्हाउचर कोड विशिष्ट लेखकाशी जोडला जातो, त्यामुळे इतरांना तो पुन्हा वापरता येत नाही.

## सध्याचा पॅकेज संदर्भ

हे पान मुद्दामच फक्त एक आढावा आहे, सेटअप मार्गदर्शकाची प्रत नाही. सध्याची आव्हान नावे, Bitsocial CLI उदाहरणे, pkc-js नोंदणी, समर्थित पर्याय आणि रिडेम्प्शनचे वर्तन यांसाठी पॅकेजचे README हेच अधिकृत स्रोत आहे:

- [व्हाउचर आव्हान README](https://github.com/bitsocialnet/voucher-challenge#readme)

थेट चालू असलेला समुदाय कॉन्फिगर करताना अपस्ट्रीम README ला प्राधान्य द्या, कारण व्हाउचरचे पर्याय आणि इन्स्टॉल प्रवाह या संकेतस्थळासोबत नव्हे तर त्या पॅकेजसोबत आवृत्तीबद्ध केले जातात.

## ते कधी वापरावे

व्हाउचर आव्हान यांसाठी सर्वाधिक योग्य आहे:

- **फक्त-आमंत्रणाने प्रवेश असलेले समुदाय**, जिथे सदस्यत्व मुद्दामच मर्यादित ठेवलेले असते.
- **निवडक जागा**, जिथे मालक प्रत्येक सहभागीची स्वतः छाननी करतो.
- **उच्च-विश्वासाची वातावरणे**, जिथे स्वयंचलित स्पॅम स्कोअरिंग अनावश्यक किंवा नकोसे असते.

कोड मॅन्युअली वाटावे लागत असल्यामुळे मोठ्या खुल्या समुदायांसाठी ते व्यवहार्य ठरत नाही. अशा परिस्थितीत त्याऐवजी [स्पॅम ब्लॉकर](./spam-blocker.md) किंवा [EVM कॉन्ट्रॅक्ट कॉल आव्हान](./evm-contract-call.md) यांचा विचार करा.
