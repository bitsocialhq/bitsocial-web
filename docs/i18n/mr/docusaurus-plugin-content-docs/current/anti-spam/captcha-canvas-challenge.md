# कॅप्चा कॅनव्हास आव्हान

कॅप्चा कॅनव्हास आव्हान हे Bitsocial समुदायांसाठीचे स्वतंत्र इमेज कॅप्चा पॅकेज आहे. ते कॅनव्हासवर यादृच्छिक मजकूर रेखाटते आणि प्रकाशन स्वीकारण्यापूर्वी लेखकांना ती प्रतिमा सोडवायला सांगण्याची मुभा समुदायाला देते.

- **स्रोत कोड आणि सध्याचे README:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **npm पॅकेज:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## इन्स्टॉलेशन

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## हे कुठे बसते

कमी जोखमीच्या स्पॅम प्रतिकारासाठी समुदायाला साधा संवादात्मक अडसर हवा असेल, तेव्हा कॅप्चा आव्हाने उपयुक्त ठरतात. हे पॅकेज मुद्दामच मर्यादित ठेवले आहे: ते फक्त आव्हानाची अंमलबजावणी पुरवते, तर ते कधी आणि कसे दाखवायचे हे समुदाय किंवा Bitsocial नोड ठरवतो.

अधिक भक्कम संरक्षणासाठी कॅप्चालाच संपूर्ण अँटी-स्पॅम रणनीती मानण्याऐवजी ते व्यापक मॉडरेशन किंवा जोखीम-स्कोअरिंग प्रणालींसोबत वापरा.

## सध्याचा पॅकेज संदर्भ

हे पान मुद्दामच फक्त एक आढावा आहे, सेटअप मार्गदर्शकाची प्रत नाही. सध्याची आव्हान नावे, नोंदणीची उदाहरणे, CLI उदाहरणे, समर्थित पर्याय, आवश्यकता आणि सुरक्षाविषयक टिपा यांसाठी पॅकेजचे README हेच अधिकृत स्रोत आहे:

- [कॅप्चा कॅनव्हास आव्हान README](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)

थेट चालू असलेला समुदाय कॉन्फिगर करताना अपस्ट्रीम README ला प्राधान्य द्या, कारण पॅकेजचे पर्याय आणि इन्स्टॉल प्रवाह या संकेतस्थळासोबत नव्हे तर त्या पॅकेजसोबत आवृत्तीबद्ध केले जातात.
