# Bitsocial CLI

`bitsocial-cli` हे Bitsocial प्रोटोकॉल बॅकएंडशी संवाद साधण्यासाठीचे कमांड-लाइन साधन आहे. त्याद्वारे तुम्ही स्थानिक P2P डीमन चालवू शकता, समुदाय तयार करून कॉन्फिगर करू शकता आणि सामग्री प्रकाशित करू शकता -- हे सर्व टर्मिनलमधून.

ते सामायिक Bitsocial प्रोटोकॉल क्लायंट स्तरावर उभारलेले असून समुदाय निर्मिती आणि नोड व्यवस्थापनासाठी [5chan](/apps/5chan/) व [Seedit](/apps/seedit/) ते वापरतात.

## स्थापना

Windows, macOS आणि Linux साठी पूर्वनिर्मित बायनरी उपलब्ध आहेत. तुमच्या प्लॅटफॉर्मसाठीचे नवीनतम प्रकाशन GitHub वरून डाउनलोड करा:

**[GitHub Releases वरून डाउनलोड करा](https://github.com/bitsocialnet/bitsocial-cli/releases)**

डाउनलोड केल्यानंतर बायनरी एक्झिक्युटेबल करा (macOS/Linux):

```bash
chmod +x bitsocial
```

## डीमन चालवणे

CLI चा सर्वात सामान्य उपयोग म्हणजे Bitsocial नोड चालवणे. डीमन P2P नेटवर्किंग स्तर सुरू करतो आणि क्लायंट जोडले जाऊ शकतील असे स्थानिक API उघड करतो.

```bash
bitsocial daemon
```

पहिल्यांदा सुरू केल्यावर डीमन **WebUI** चे दुवे दाखवतो. WebUI हा तुमचा नोड, समुदाय आणि सेटिंग्ज व्यवस्थापित करण्यासाठीचा ब्राउझर-आधारित ग्राफिकल इंटरफेस आहे. टर्मिनल कमांडपेक्षा GUI तुम्हाला अधिक सोयीचा वाटत असेल तर हे उपयुक्त ठरते.

## मुख्य क्रिया

| क्रिया                      | वर्णन                                                   |
| --------------------------- | ------------------------------------------------------- |
| डीमन सुरू करा               | Bitsocial P2P नोड सुरू करा                              |
| समुदाय तयार करा             | नवीन समुदाय तयार करा                                    |
| समुदाय संपादित करा          | समुदायाच्या सेटिंग्ज अद्ययावत करा (शीर्षक, वर्णन, नियम) |
| स्थानिक समुदायांची यादी करा | या नोडवर होस्ट केलेल्या समुदायांची यादी करा             |
| समुदाय सुरू करा             | विशिष्ट समुदाय पुरवणे सुरू करा                          |
| समुदाय थांबवा               | विशिष्ट समुदाय पुरवणे थांबवा                            |

तुम्ही स्थापित केलेल्या प्रकाशनात उपलब्ध असलेली सध्याची कमांड नावे आणि फ्लॅग पाहण्यासाठी CLI `--help` सह चालवा:

```bash
bitsocial --help
bitsocial daemon --help
```

## नेहमीचा कार्यप्रवाह

नवीन समुदाय होस्ट करण्यासाठीचा सामान्य सेटअप प्रवाह:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

तिथून पुढे, समुदाय तयार करण्यासाठी, कॉन्फिगर करण्यासाठी आणि पुरवणे सुरू करण्यासाठी स्थापित प्रकाशनातील समुदाय-व्यवस्थापन कमांड वापरा. एकदा सुरू झाल्यावर समुदाय Bitsocial नेटवर्कवर थेट उपलब्ध होतो आणि सुसंगत क्लायंटमधून वापरता येतो.
