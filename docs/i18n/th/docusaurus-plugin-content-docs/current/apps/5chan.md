# 5chan

5chan เป็นอิมเมจบอร์ดแบบไร้เซิร์ฟเวอร์ ไร้ผู้ดูแลระบบ และกระจายอำนาจเต็มรูปแบบ ที่ทำงานบนโปรโตคอล Bitsocial มันใช้โครงสร้างไดเรกทอรีแบบอิมเมจบอร์ดที่คุ้นเคย พร้อมกับเพิ่มความเป็นเจ้าของแบบกระจายอำนาจเข้ามา — ใครก็สร้างบอร์ดได้ และหลายบอร์ดแข่งขันกันเพื่อชิงช่องไดเรกทอรีเดียวกันผ่านกลไกการโหวตได้

## ดาวน์โหลด

| แพลตฟอร์ม | ลิงก์                              |
| --------- | ---------------------------------- |
| เว็บ      | [5chan.app](https://5chan.app)     |
| เดสก์ท็อป | ใช้งานได้บน Mac, Windows และ Linux |
| มือถือ    | ใช้งานได้บน Android                |

## บอร์ดทำงานอย่างไร

5chan จัดระเบียบเนื้อหาออกเป็นบอร์ดโดยใช้เลย์เอาต์ไดเรกทอรีแบบคลาสสิก (เช่น `/b/`, `/g/`) ต่างจากอิมเมจบอร์ดดั้งเดิมที่ผู้ดูแลระบบส่วนกลางควบคุมทุกบอร์ด 5chan เปิดให้ผู้ใช้คนใดก็ได้สร้างและเป็นเจ้าของบอร์ดของตัวเองอย่างเต็มที่ เมื่อหลายบอร์ดเล็งช่องไดเรกทอรีเดียวกัน บอร์ดเหล่านั้นจะแข่งขันกันเพื่อชิงตำแหน่งนั้นด้วยการโหวต

### การสร้างบอร์ด

หากต้องการสร้างบอร์ดใหม่ คุณต้องรัน `bitsocial-cli` ในฐานะโหนดเพียร์ทูเพียร์ วิธีนี้ทำให้บอร์ดของคุณถูกโฮสต์แบบกระจายอำนาจ โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ส่วนกลางใดๆ

### การกำหนดช่องไดเรกทอรี

การกำหนดช่องไดเรกทอรี (ว่าบอร์ดใดจะปรากฏที่เส้นทางใด) ปัจจุบันจัดการผ่าน pull request บน GitHub ไปยังไฟล์ `5chan-directories.json` นี่เป็นกระบวนการชั่วคราว — รุ่นถัดๆ ไปจะรองรับการสร้างบอร์ดภายในแอปและการโหวตผ่าน pubsub เพื่อจัดการการกำหนดช่องไดเรกทอรีโดยอัตโนมัติ

## กลไกภายใน

เบื้องหลังนั้น 5chan ใช้เลเยอร์ไคลเอนต์ของโปรโตคอล Bitsocial ที่ใช้ร่วมกันสำหรับการติดต่อกับเครือข่าย เว็บแอปที่ 5chan.app รันโหนด Helia ในเบราว์เซอร์เป็นค่าเริ่มต้น แท็บธรรมดาจึงเข้าร่วมเครือข่ายในฐานะเพียร์ นั่นคือมันโหลดบอร์ดจากเพียร์รายอื่นและเผยแพร่ผ่าน pubsub โดยไม่มีเกตเวย์ IPFS แบบรวมศูนย์อยู่ในเส้นทางของเนื้อหา ดูได้ที่ [เพียร์ทูเพียร์ในเบราว์เซอร์](/browser-p2p/) ว่าสิ่งนี้เกี่ยวข้องกับอะไรบ้าง และโหนดในเบราว์เซอร์ยังทำอะไรไม่ได้
