# นโยบายภาษาเริ่มต้นของ i18n

ระบบจะกำหนดภาษาให้ผู้เข้าชมที่ไม่ได้ระบุตัวตนตามลำดับต่อไปนี้:

1. พารามิเตอร์ `?lang=` ใน URL
2. ภาษาที่เคยเลือกไว้จากตัวเลือกภาษา (เก็บใน `localStorage` ของเบราว์เซอร์ และคัดลอกไปยังคุกกี้ `i18nextLng` สำหรับการเรนเดอร์ฝั่งเซิร์ฟเวอร์)
3. ภาษาของเบราว์เซอร์หรืออุปกรณ์ เมื่อเป็นหนึ่งในภาษาที่เรารองรับ
4. ย้อนกลับไปใช้ `en`

เราไม่ใช้ประเทศหรือภูมิภาคมาแทนที่ภาษาของเบราว์เซอร์หรืออุปกรณ์ที่รองรับอยู่แล้ว ตัวอย่างเช่น `de-DE` จะได้ภาษาเยอรมัน `nl-NL` จะได้ภาษาดัตช์ และ `pt-PT` จะได้ภาษาโปรตุเกส เพราะตระกูลภาษาเหล่านั้นอยู่ในรายการที่รองรับ

หากไม่มีภาษาของเบราว์เซอร์หรืออุปกรณ์ใดตรงกับภาษาที่รองรับ ผู้เข้าชมจะได้รับค่าเริ่มต้นเป็นภาษาอังกฤษ
