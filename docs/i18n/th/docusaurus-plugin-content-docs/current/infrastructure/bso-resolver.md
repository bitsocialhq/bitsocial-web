# BSO Resolver

BSO Resolver แปลงชื่อโดเมน `.bso` ให้เป็นคีย์สาธารณะที่ตรงกัน โดยอ่านจากเรกคอร์ด TXT ของ Bitsocial มันคือแพ็กเกจ resolver ที่เครื่องมือต่าง ๆ ของ Bitsocial เรียกใช้ เมื่อชื่อ `.bso` ที่ผู้ใช้เห็นต้องถูกแปลงเป็นคีย์ที่สแตกเพียร์ทูเพียร์เข้าใจ

- **ซอร์สโค้ดและ README ปัจจุบัน:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **แพ็กเกจ npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## การติดตั้ง

```bash
npm install @bitsocial/bso-resolver
```

## มันอยู่ตรงไหนของระบบ

ชื่อใน Bitsocial ถูกออกแบบให้เป็นจุดเริ่มต้นที่มนุษย์อ่านได้สำหรับชุมชนและผู้เขียน resolver แยกเลเยอร์การตั้งชื่อนี้ออกจากโค้ดของแอปพลิเคชัน ไคลเอ็นต์จึงถามได้ก่อนว่าชื่อหนึ่งรองรับหรือไม่ แล้วค่อยแปลงชื่อนั้นผ่านจุดเริ่มต้นการใช้งานที่ตรงกับรันไทม์ของแพ็กเกจ

ใช้มันเมื่อคุณกำลังเชื่อมต่อไคลเอ็นต์ เครื่องมือบรรทัดคำสั่ง หรือบริการที่รู้จัก Bitsocial ซึ่งต้องรับชื่อ `.bso` ได้ ไม่ใช่รับเฉพาะคีย์สาธารณะดิบเท่านั้น
