# EVM Contract Call Challenge

EVM Contract Call Challenge ตรวจสอบสถานะบนเชนของผู้เขียนก่อนจะอนุญาตให้เผยแพร่เนื้อหา เจ้าของชุมชนกำหนดได้ว่ากระเป๋าเงินหรืออัตลักษณ์ที่แปลงค่าแล้วต้องผ่านเงื่อนไขของสัญญาอัจฉริยะแบบอ่านอย่างเดียวเสียก่อน เช่น ถือโทเค็นไม่ต่ำกว่าจำนวนที่กำหนด จึงจะโพสต์ได้

- **ซอร์สโค้ดและ README ฉบับปัจจุบัน:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **แพ็กเกจ npm:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## การติดตั้ง

```bash
npm install @bitsocial/evm-contract-challenge
```

## เหมาะกับงานแบบไหน

ใช้ความท้าทายนี้กับชุมชนที่การเข้าร่วมควรขึ้นอยู่กับสัญญาณจากภายนอกบน EVM ไม่ว่าจะเป็นการถือครองโทเค็น การถือครอง NFT คะแนนพิสูจน์ความเป็นมนุษย์ การเป็นสมาชิกของกลไกกำกับดูแล หรือเงื่อนไขอื่นที่อ่านได้จากสัญญา

เมื่อตั้งค่าเรียบร้อยแล้ว ความท้าทายนี้จะทำงานอัตโนมัติในมุมมองของผู้เขียน มันจะตรวจสอบแหล่งกระเป๋าเงินหรืออัตลักษณ์ที่เข้าเกณฑ์ เรียกเมธอดของสัญญาตามที่กำหนดค่าไว้ แล้วเปรียบเทียบค่าที่ได้กลับมากับเงื่อนไขของชุมชน

## เอกสารอ้างอิงฉบับปัจจุบันของแพ็กเกจ

หน้านี้ตั้งใจให้เป็นภาพรวม ไม่ใช่เอกสารอ้างอิงการกำหนดค่าที่คัดลอกมาทั้งหมด README ของแพ็กเกจคือแหล่งข้อมูลที่ถูกต้องสำหรับชื่อความท้าทาย ตัวอย่างการใช้ Bitsocial CLI การลงทะเบียนกับ pkc-js ค่าเริ่มต้นของตัวเลือก ตัวอย่าง ABI พฤติกรรมของ RPC และแหล่งกระเป๋าเงินที่รองรับ:

- [README ของ EVM Contract Challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)

เมื่อกำลังตั้งค่าชุมชนที่ใช้งานจริง ให้ยึด README ต้นทางเป็นหลัก เพราะตัวเลือกของสัญญาและตัวอย่างต่างๆ ถูกกำหนดเวอร์ชันไปพร้อมกับแพ็กเกจนั้น ไม่ใช่พร้อมกับเว็บไซต์นี้

## ควรใช้เมื่อใด

EVM Contract Call Challenge เหมาะอย่างยิ่งกับ:

- **ชุมชนที่กั้นด้วยโทเค็น** ซึ่งจำกัดการโพสต์ไว้เฉพาะผู้ถือโทเค็น
- **การเข้าถึงที่กั้นด้วย NFT** ซึ่งต้องถือครอง NFT ที่กำหนดไว้
- **พื้นที่กำกับดูแลของ DAO** ซึ่งจำกัดการเข้าร่วมไว้เฉพาะผู้ถือโทเค็นกำกับดูแล

สำหรับชุมชนที่ไม่ได้พึ่งพาอัตลักษณ์บนเชน ให้พิจารณา [Spam Blocker](./spam-blocker.md) หรือ [Voucher Challenge](./voucher-challenge.md) แทน
