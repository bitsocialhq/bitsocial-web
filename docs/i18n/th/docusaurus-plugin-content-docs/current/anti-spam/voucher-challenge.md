# Voucher Challenge

Voucher Challenge กั้นการเผยแพร่เนื้อหาไว้หลังรหัสบัตรกำนัลเฉพาะตัวที่เจ้าของชุมชนเป็นผู้แจกจ่าย แทนที่จะพึ่งพาการให้คะแนนอัตโนมัติ มันย้ายความไว้วางใจไปไว้ที่ขั้นตอนการเชิญด้วยมือ ซึ่งคนที่เจ้าของชุมชนรู้จักจะได้รับรหัสผ่านช่องทางที่เจ้าของควบคุมเอง

- **ซอร์สโค้ดและ README ฉบับปัจจุบัน:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **แพ็กเกจ npm:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## การติดตั้ง

```bash
npm install @bitsocial/voucher-challenge
```

## วิธีการทำงาน

1. เจ้าของชุมชนสร้างรหัสบัตรกำนัลเฉพาะตัวขึ้นมาหนึ่งรหัสหรือมากกว่านั้น
2. เจ้าของแจกจ่ายรหัสเหล่านั้นให้ผู้เขียนที่ไว้ใจได้ผ่านช่องทางที่ตนเลือก (ข้อความส่วนตัว อีเมล การส่งมอบต่อหน้า ฯลฯ)
3. เมื่อผู้เขียนพยายามเผยแพร่เนื้อหา ระบบความท้าทายจะขอรหัสบัตรกำนัลจากเขา
4. รหัสจะถูกตรวจสอบ -- หากเป็นรหัสจริงและยังไม่เคยถูกใช้มาก่อน การเผยแพร่จะได้รับการยอมรับ

รหัสบัตรกำนัลแต่ละรหัสจะผูกกับผู้เขียนรายใดรายหนึ่งทันทีที่ถูกใช้ไปแล้ว จึงป้องกันไม่ให้คนอื่นนำไปใช้ซ้ำ

## เอกสารอ้างอิงฉบับปัจจุบันของแพ็กเกจ

หน้านี้ตั้งใจให้เป็นภาพรวม ไม่ใช่คู่มือการตั้งค่าที่คัดลอกมาทั้งหมด README ของแพ็กเกจคือแหล่งข้อมูลที่ถูกต้องสำหรับชื่อความท้าทายในปัจจุบัน ตัวอย่างการใช้ Bitsocial CLI การลงทะเบียนกับ pkc-js ตัวเลือกที่รองรับ และพฤติกรรมการใช้รหัสแลก:

- [README ของ Voucher Challenge](https://github.com/bitsocialnet/voucher-challenge#readme)

เมื่อกำลังตั้งค่าชุมชนที่ใช้งานจริง ให้ยึด README ต้นทางเป็นหลัก เพราะตัวเลือกของบัตรกำนัลและขั้นตอนการติดตั้งถูกกำหนดเวอร์ชันไปพร้อมกับแพ็กเกจนั้น ไม่ใช่พร้อมกับเว็บไซต์นี้

## ควรใช้เมื่อใด

Voucher Challenge เหมาะที่สุดกับ:

- **ชุมชนที่เข้าร่วมได้ด้วยคำเชิญเท่านั้น** ซึ่งจงใจจำกัดสมาชิกภาพ
- **พื้นที่ที่คัดสรรผู้เข้าร่วม** ซึ่งเจ้าของตรวจสอบผู้เข้าร่วมทุกคนด้วยตัวเอง
- **สภาพแวดล้อมที่ไว้วางใจกันสูง** ซึ่งการให้คะแนนสแปมอัตโนมัติไม่จำเป็นหรือไม่พึงประสงค์

เนื่องจากต้องแจกจ่ายรหัสด้วยมือ มันจึงขยายไปสู่ชุมชนเปิดขนาดใหญ่ไม่ได้ สำหรับสถานการณ์เหล่านั้น ให้พิจารณา [Spam Blocker](./spam-blocker.md) หรือ [EVM Contract Call Challenge](./evm-contract-call.md) แทน
