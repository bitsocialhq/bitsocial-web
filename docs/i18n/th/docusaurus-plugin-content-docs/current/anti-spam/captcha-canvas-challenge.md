# Captcha Canvas Challenge

Captcha Canvas Challenge เป็นแพ็กเกจแคปต์ชาแบบรูปภาพชนิดสแตนด์อโลนสำหรับชุมชน Bitsocial มันเรนเดอร์ข้อความที่สุ่มขึ้นมาลงบนแคนวาส และเปิดให้ชุมชนกำหนดให้ผู้เขียนต้องแก้ภาพนั้นก่อนที่การเผยแพร่จะได้รับการยอมรับ

- **ซอร์สโค้ดและ README ฉบับปัจจุบัน:** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **แพ็กเกจ npm:** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## การติดตั้ง

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## เหมาะกับงานแบบไหน

ความท้าทายแบบแคปต์ชามีประโยชน์เมื่อชุมชนต้องการด่านโต้ตอบง่ายๆ ไว้กันสแปมในสถานการณ์ที่เดิมพันไม่สูงนัก แพ็กเกจนี้จงใจทำขอบเขตให้แคบ คือให้เฉพาะการนำความท้าทายไปใช้งาน ส่วนชุมชนหรือโหนด Bitsocial เป็นผู้ตัดสินใจว่าจะแสดงมันเมื่อใดและอย่างไร

หากต้องการการป้องกันที่แข็งแรงกว่านี้ ให้ใช้ร่วมกับระบบกำกับดูแลเนื้อหาหรือระบบให้คะแนนความเสี่ยงในวงกว้าง แทนที่จะมองว่าแคปต์ชาเป็นกลยุทธ์ต่อต้านสแปมที่ครบถ้วนในตัวเอง
