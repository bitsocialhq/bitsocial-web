# Bitsocial CLI

`bitsocial-cli` คือเครื่องมือบรรทัดคำสั่งสำหรับโต้ตอบกับแบ็กเอนด์ของโปรโตคอล Bitsocial มันช่วยให้คุณรันเดมอน P2P ในเครื่อง สร้างและกำหนดค่าชุมชน และเผยแพร่เนื้อหา -- ทั้งหมดนี้จากเทอร์มินัล

เครื่องมือนี้สร้างขึ้นบนเลเยอร์ไคลเอ็นต์โปรโตคอลของ Bitsocial ที่ใช้ร่วมกัน และถูกใช้โดย [5chan](/apps/5chan/) และ [Seedit](/apps/seedit/) สำหรับการสร้างชุมชนและการจัดการโหนด

## การติดตั้ง

มีไบนารีที่คอมไพล์ไว้แล้วสำหรับ Windows, macOS และ Linux ดาวน์โหลดรุ่นล่าสุดสำหรับแพลตฟอร์มของคุณได้จาก GitHub:

**[ดาวน์โหลดจาก GitHub Releases](https://github.com/bitsocialnet/bitsocial-cli/releases)**

หลังดาวน์โหลดแล้ว ให้ตั้งค่าไบนารีให้รันได้ (macOS/Linux):

```bash
chmod +x bitsocial
```

## การรันเดมอน

การใช้งาน CLI ที่พบบ่อยที่สุดคือการรันโหนด Bitsocial เดมอนจะเริ่มเลเยอร์เครือข่าย P2P และเปิด API ในเครื่องให้ไคลเอ็นต์เชื่อมต่อเข้ามาได้

```bash
bitsocial daemon
```

เมื่อเปิดใช้ครั้งแรก เดมอนจะแสดงลิงก์ไปยัง **WebUI** ซึ่งเป็นอินเทอร์เฟซแบบกราฟิกบนเบราว์เซอร์สำหรับจัดการโหนด ชุมชน และการตั้งค่าของคุณ มีประโยชน์หากคุณถนัด GUI มากกว่าคำสั่งในเทอร์มินัล

## การกระทำหลัก

| การกระทำ                 | รายละเอียด                               |
| ------------------------ | ---------------------------------------- |
| เริ่มเดมอน               | เปิดโหนด P2P ของ Bitsocial               |
| สร้างชุมชน               | สร้างชุมชนใหม่                           |
| แก้ไขชุมชน               | อัปเดตการตั้งค่าชุมชน (ชื่อ คำอธิบาย กฎ) |
| แสดงรายการชุมชนในเครื่อง | แสดงรายการชุมชนที่โฮสต์อยู่บนโหนดนี้     |
| เริ่มให้บริการชุมชน      | เริ่มให้บริการชุมชนที่ระบุ               |
| หยุดให้บริการชุมชน       | หยุดให้บริการชุมชนที่ระบุ                |

รัน CLI พร้อม `--help` เพื่อดูชื่อคำสั่งและแฟล็กปัจจุบันที่รุ่นซึ่งคุณติดตั้งไว้เปิดให้ใช้งาน:

```bash
bitsocial --help
bitsocial daemon --help
```

## ขั้นตอนการทำงานทั่วไป

ขั้นตอนการตั้งค่าที่พบบ่อยสำหรับการโฮสต์ชุมชนใหม่:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

จากนั้นให้ใช้คำสั่งจัดการชุมชนของรุ่นที่คุณติดตั้งไว้ เพื่อสร้าง กำหนดค่า และเริ่มให้บริการชุมชน เมื่อเริ่มแล้ว ชุมชนจะออนไลน์อยู่บนเครือข่าย Bitsocial และเข้าถึงได้จากไคลเอ็นต์ที่รองรับ
