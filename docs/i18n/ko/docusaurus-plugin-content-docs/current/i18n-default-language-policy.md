# i18n 기본 언어 정책

익명 방문자의 언어는 다음 순서로 결정됩니다.

1. `?lang=` 쿼리 파라미터
2. 언어 선택기에 저장된 선택값(브라우저의 `localStorage`에 저장되며, SSR을 위해 `i18nextLng` 쿠키에도 반영됩니다)
3. 브라우저/기기 언어가 지원 로케일 중 하나인 경우 해당 언어
4. 그 외에는 `en`으로 폴백

지원되는 브라우저/기기 언어를 국가나 지역 정보로 덮어쓰지 않습니다. 예를 들어 `de-DE`는 독일어로, `nl-NL`은 네덜란드어로, `pt-PT`는 포르투갈어로 해석되는데, 이는 해당 로케일 계열을 지원하기 때문입니다.

브라우저/기기 언어가 지원 로케일 중 어느 것과도 일치하지 않으면 방문자에게는 기본값인 영어가 제공됩니다.
