# Bitsocial 경제권 확장

4단계의 목표는 생태계를 충분히 크게 키워서, 어떤 회사나 RPC, 호스팅 제공자, 클라이언트도 새로운
플랫폼 소유자가 되지 못하게 만드는 것입니다.

첫 공개 RPC와 첫 주요 서비스는 Bitsocial Forge가 만들 수 있지만, 거기서 멈춰서는 안 됩니다.
여러 기업, 팀, 익명 운영자, 커뮤니티 조직, 독립 개발자가 Bitsocial 위에서 쓸 만한 인프라를 만들
수 있을 때 네트워크는 더 건강해집니다.

## 무엇이 확장되어야 하나

생태계에는 앱만으로는 부족합니다.

- 서로 경쟁하는 공개 RPC
- 미디어 호스팅 서비스
- 탐색 및 인덱싱 서비스
- 모더레이션 서비스
- 피드 알고리즘 제공자
- 프로필 노드 호스팅
- 분석과 관측
- 개발자 도구
- 보조금과 자금 지원 창구

각 서비스는 대체 가능해야 합니다. 좋은 제공자가 성공하는 것은 좋지만, 사용자와 앱에는 언제나
갈 수 있는 다른 선택지가 남아 있어야 합니다.

## 탈중앙화 수단으로서의 자금 지원

자금 지원은 네트워크를 하나의 영구적인 중심으로 몰아가는 대신, 독립 운영자가 더 많아지는 쪽으로
밀어야 합니다.

즉 클라이언트, 인프라, 모더레이션 도구, 인덱싱 도구, 모바일 경험, 미디어 서비스, 경쟁 RPC를
만드는 개발자에게 자금을 지원한다는 뜻입니다. 동시에 기업, 커뮤니티 조직, 익명 운영자, 1인
개발자가 네트워크 안에서 지속 가능한 사업을 찾을 여지를 남겨둔다는 뜻이기도 합니다.

## 경제권이 중요한 이유

소셜 인프라를 유지하는 데는 비용이 많이 듭니다. RPC, 호스팅, 탐색, 개발 비용을 한 조직이 전부
부담한다면, 프로토콜이 P2P라 해도 네트워크는 여전히 취약합니다.

더 튼튼한 형태는 프로토콜 주위에 형성된 서비스 시장입니다.

- 클라이언트는 사용자를 두고 경쟁합니다
- RPC는 안정성과 신뢰 모델로 경쟁합니다
- 미디어 호스트는 가격과 정책으로 경쟁합니다
- 탐색 서비스는 관련성으로 경쟁합니다
- 개발자는 보조금, 매출, 평판을 두고 경쟁합니다

Bitsocial 경제권은 쓸모 있는 일에 여러 독립 주체가 자금을 댈 수 있게 만들고, 그럼으로써
프로토콜을 장악하기 어렵게 만들어야 합니다.
