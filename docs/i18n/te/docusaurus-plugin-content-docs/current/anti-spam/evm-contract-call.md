# EVM Contract Call Challenge

EVM Contract Call Challenge ఒక ప్రచురణను అనుమతించే ముందు రచయిత ఆన్-చెయిన్ స్థితిని ధృవీకరిస్తుంది. పోస్ట్ చేయడానికి ముందు కనీస టోకెన్ బ్యాలెన్స్ కలిగి ఉండటం వంటి, చదవడానికి-మాత్రమే అయిన స్మార్ట్-కాంట్రాక్ట్ షరతును ఒక వాలెట్ లేదా పరిష్కరించబడిన గుర్తింపు సంతృప్తిపరచాలని కమ్యూనిటీ యజమానులు కోరవచ్చు.

- **సోర్స్ కోడ్ మరియు ప్రస్తుత README:** [github.com/bitsocialnet/evm-contract-challenge](https://github.com/bitsocialnet/evm-contract-challenge#readme)
- **npm ప్యాకేజీ:** [`@bitsocial/evm-contract-challenge`](https://www.npmjs.com/package/@bitsocial/evm-contract-challenge)

## ఇన్‌స్టాలేషన్

```bash
npm install @bitsocial/evm-contract-challenge
```

## ఇది ఎక్కడ సరిపోతుంది

పాల్గొనడం ఒక బాహ్య EVM సంకేతంపై ఆధారపడాల్సిన కమ్యూనిటీల కోసం ఈ ఛాలెంజ్‌ను వాడండి: టోకెన్ యాజమాన్యం, NFT యాజమాన్యం, ప్రూఫ్-ఆఫ్-పర్సన్‌హుడ్ స్కోర్లు, గవర్నెన్స్ సభ్యత్వం, లేదా కాంట్రాక్ట్ ద్వారా చదవగలిగే మరో షరతు.

ఒకసారి కాన్ఫిగర్ చేసిన తర్వాత రచయిత దృష్టిలో ఈ ఛాలెంజ్ స్వయంచాలకంగా జరిగిపోతుంది. ఇది అర్హత గల వాలెట్ లేదా గుర్తింపు మూలాలను తనిఖీ చేసి, కాన్ఫిగర్ చేసిన కాంట్రాక్ట్ మెథడ్‌ను పిలిచి, తిరిగి వచ్చిన విలువను కమ్యూనిటీ షరతుతో పోల్చుతుంది.

## ప్రస్తుత ప్యాకేజీ సూచన

ఈ పేజీ ఉద్దేశపూర్వకంగానే ఒక సమగ్ర పరిచయం, ప్రతిబింబించిన కాన్ఫిగరేషన్ సూచిక కాదు. ఛాలెంజ్ పేర్లు, Bitsocial CLI ఉదాహరణలు, pkc-js రిజిస్ట్రేషన్, ఆప్షన్ డిఫాల్ట్‌లు, ABI ఉదాహరణలు, RPC ప్రవర్తన మరియు మద్దతు ఉన్న వాలెట్ మూలాలకు ప్యాకేజీ README మూలాధారం:

- [EVM Contract Challenge README](https://github.com/bitsocialnet/evm-contract-challenge#readme)

కాంట్రాక్ట్ ఆప్షన్లు, ఉదాహరణలు ఈ వెబ్‌సైట్‌తో కాకుండా ఆ ప్యాకేజీతో పాటే వెర్షన్ చేయబడతాయి కాబట్టి, ఒక సజీవ కమ్యూనిటీని కాన్ఫిగర్ చేసేటప్పుడు అప్‌స్ట్రీమ్ READMEకే ప్రాధాన్యం ఇవ్వండి.

## దీన్ని ఎప్పుడు వాడాలి

EVM Contract Call Challenge వీటికి అనువైనది:

- **టోకెన్-గేటెడ్ కమ్యూనిటీలు**, ఇవి పోస్ట్ చేయడాన్ని టోకెన్ హోల్డర్లకే పరిమితం చేస్తాయి.
- **NFT-గేటెడ్ యాక్సెస్**, ఇక్కడ ఒక నిర్దిష్ట NFT యాజమాన్యం తప్పనిసరి.
- **DAO గవర్నెన్స్ స్థలాలు**, ఇక్కడ పాల్గొనడం గవర్నెన్స్ టోకెన్ హోల్డర్లకే పరిమితం.

ఆన్-చెయిన్ గుర్తింపుపై ఆధారపడని కమ్యూనిటీలు దీనికి బదులుగా [Spam Blocker](./spam-blocker.md) లేదా [Voucher Challenge](./voucher-challenge.md) పరిశీలించవచ్చు.
