# Voucher Challenge

కమ్యూనిటీ యజమాని పంపిణీ చేసే ప్రత్యేక వోచర్ కోడ్‌ల వెనుక Voucher Challenge కంటెంట్ ప్రచురణను నియంత్రిస్తుంది. స్వయంచాలక స్కోరింగ్‌పై ఆధారపడే బదులు, యజమాని నియంత్రించే ఒక మార్గం ద్వారా తెలిసిన వ్యక్తులకు కోడ్‌లు అందే మాన్యువల్ ఆహ్వాన ప్రవాహం వైపు ఇది నమ్మకాన్ని మళ్లిస్తుంది.

- **సోర్స్ కోడ్ మరియు ప్రస్తుత README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **npm ప్యాకేజీ:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## ఇన్‌స్టాలేషన్

```bash
npm install @bitsocial/voucher-challenge
```

## ఇది ఎలా పనిచేస్తుంది

1. కమ్యూనిటీ యజమాని ఒకటి లేదా అంతకంటే ఎక్కువ ప్రత్యేక వోచర్ కోడ్‌లను రూపొందిస్తారు.
2. తనకు నచ్చిన మార్గం ద్వారా (డైరెక్ట్ మెసేజ్, ఇమెయిల్, ప్రత్యక్షంగా మొదలైనవి) ఆ కోడ్‌లను యజమాని నమ్మకమైన రచయితలకు పంపిణీ చేస్తారు.
3. ఒక రచయిత ప్రచురించడానికి ప్రయత్నించినప్పుడు, ఛాలెంజ్ వ్యవస్థ వారిని వోచర్ కోడ్ అడుగుతుంది.
4. కోడ్ ధృవీకరించబడుతుంది -- అది నిజమైనదై, ఇంతకుముందు వాడబడకపోతే, ప్రచురణ ఆమోదించబడుతుంది.

ఒకసారి రిడీమ్ చేసిన తర్వాత ప్రతి వోచర్ కోడ్ ఒక నిర్దిష్ట రచయితతో ముడిపడి ఉంటుంది, దీనివల్ల ఇతరులు దాన్ని మళ్లీ వాడలేరు.

## ప్రస్తుత ప్యాకేజీ సూచన

ఈ పేజీ ఉద్దేశపూర్వకంగానే ఒక సమగ్ర పరిచయం, ప్రతిబింబించిన సెటప్ గైడ్ కాదు. ప్రస్తుత ఛాలెంజ్ పేర్లు, Bitsocial CLI ఉదాహరణలు, pkc-js రిజిస్ట్రేషన్, మద్దతు ఉన్న ఆప్షన్లు మరియు రిడెంప్షన్ ప్రవర్తనకు ప్యాకేజీ README మూలాధారం:

- [Voucher Challenge README](https://github.com/bitsocialnet/voucher-challenge#readme)

వోచర్ ఆప్షన్లు, ఇన్‌స్టాల్ ప్రవాహాలు ఈ వెబ్‌సైట్‌తో కాకుండా ఆ ప్యాకేజీతో పాటే వెర్షన్ చేయబడతాయి కాబట్టి, ఒక సజీవ కమ్యూనిటీని కాన్ఫిగర్ చేసేటప్పుడు అప్‌స్ట్రీమ్ READMEకే ప్రాధాన్యం ఇవ్వండి.

## దీన్ని ఎప్పుడు వాడాలి

Voucher Challenge వీటికి బాగా సరిపోతుంది:

- **ఆహ్వానం-మాత్రమే కమ్యూనిటీలు**, ఇక్కడ సభ్యత్వం ఉద్దేశపూర్వకంగా పరిమితం చేయబడుతుంది.
- **క్యూరేట్ చేసిన స్థలాలు**, ఇక్కడ యజమాని ప్రతి పాల్గొనేవారినీ స్వయంగా పరిశీలిస్తారు.
- **అధిక-నమ్మక వాతావరణాలు**, ఇక్కడ స్వయంచాలక స్పామ్ స్కోరింగ్ అనవసరం లేదా అవాంఛనీయం.

మాన్యువల్‌గా కోడ్‌లు పంపిణీ చేయాల్సి ఉంటుంది కాబట్టి, ఇది పెద్ద బహిరంగ కమ్యూనిటీలకు విస్తరించదు. అలాంటి సందర్భాల కోసం దీనికి బదులుగా [Spam Blocker](./spam-blocker.md) లేదా [EVM Contract Call Challenge](./evm-contract-call.md) పరిశీలించండి.
