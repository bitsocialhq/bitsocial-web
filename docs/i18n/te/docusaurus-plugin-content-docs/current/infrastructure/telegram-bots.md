# Telegram బాట్‌లు

Bitsocial Telegram బాట్‌లు Bitsocial నెట్‌వర్క్‌లోని క్లయింట్ కమ్యూనిటీ జాబితాలను పర్యవేక్షించి, కొత్త పోస్ట్‌లను స్వయంచాలకంగా Telegram ఛానెల్‌లలోకి ఫార్వార్డ్ చేస్తాయి. ఫార్వార్డ్ చేసిన ప్రతి సందేశంలో 5chan మరియు Seeditలోని అసలు పోస్ట్‌కు తిరిగి తీసుకువెళ్లే ఇన్‌లైన్ బటన్‌లు ఉంటాయి.

- **GitHub**: [bitsocialnet/bitsocial-telegram-bots](https://github.com/bitsocialnet/bitsocial-telegram-bots)

## అందుబాటులో ఉన్న బాట్‌లు

| బాట్            | స్థితి          | వివరణ                                                                                    |
| --------------- | --------------- | ---------------------------------------------------------------------------------------- |
| **5chan Feed**  | క్రియాశీలం      | అన్ని 5chan డైరెక్టరీలను పర్యవేక్షించి కొత్త పోస్ట్‌లను Telegramకు ఫార్వార్డ్ చేస్తుంది. |
| **Seedit Feed** | ప్రణాళికలో ఉంది | Seedit కమ్యూనిటీల కోసం ఇదే కార్యాచరణను అందిస్తుంది.                                      |

## సెటప్

### ముందస్తు అవసరాలు

- Node.js
- Yarn
- Telegram బాట్ టోకెన్ ([BotFather](https://t.me/BotFather) ద్వారా ఒకటి సృష్టించండి)

### సంస్థాపన

రిపోజిటరీని క్లోన్ చేసి డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి:

```bash
git clone https://github.com/bitsocialnet/bitsocial-telegram-bots.git
cd bitsocial-telegram-bots
yarn install
```

### కాన్ఫిగరేషన్

మీ బాట్ టోకెన్‌తో ప్రాజెక్ట్ రూట్‌లో ఒక `.env` ఫైల్‌ను సృష్టించండి:

```env
BOT_TOKEN=your_telegram_bot_token
```

### అమలు చేయడం

మీ ఎన్విరాన్‌మెంట్‌ను కాన్ఫిగర్ చేసిన తర్వాత బాట్‌ను ప్రారంభించండి:

```bash
yarn start
```

## పోస్ట్ ఫార్మాట్

బాట్ ఒక పోస్ట్‌ను Telegramకు ఫార్వార్డ్ చేసినప్పుడు, అందులో రెండు ఇన్‌లైన్ బటన్‌లు ఉంటాయి:

- **5chanలో చూడండి** -- 5chan వెబ్ క్లయింట్‌లో పోస్ట్‌ను తెరుస్తుంది.
- **Seeditలో చూడండి** -- Seedit వెబ్ క్లయింట్‌లో పోస్ట్‌ను తెరుస్తుంది.

ఇది Telegram చందాదారులు తమకు నచ్చిన క్లయింట్‌లో పూర్తి చర్చా థ్రెడ్‌కు నేరుగా వెళ్లేలా చేస్తుంది.
