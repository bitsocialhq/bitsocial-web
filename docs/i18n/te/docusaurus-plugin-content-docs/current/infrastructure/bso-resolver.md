# BSO రిజల్వర్

BSO Resolver, Bitsocial TXT రికార్డులను చదవడం ద్వారా `.bso` డొమైన్ పేర్లను వాటికి సంబంధించిన పబ్లిక్ కీలుగా అనువదిస్తుంది. వినియోగదారులకు కనిపించే `.bso` పేరు, పీర్-టు-పీర్ స్టాక్‌కు అర్థమయ్యే కీ మెటీరియల్‌గా మారవలసి వచ్చినప్పుడు Bitsocial టూలింగ్ ఉపయోగించే రిజల్వర్ ప్యాకేజీ ఇది.

- **సోర్స్ కోడ్ మరియు ప్రస్తుత README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **npm ప్యాకేజీ:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## సంస్థాపన

```bash
npm install @bitsocial/bso-resolver
```

## ఇది ఎక్కడ సరిపోతుంది

Bitsocial పేర్లు కమ్యూనిటీలకు మరియు రచయితలకు మనుషులు చదవగలిగే ప్రవేశ బిందువులుగా ఉద్దేశించబడ్డాయి. రిజల్వర్ ఆ నామకరణ పొరను అప్లికేషన్ కోడ్ నుండి వేరుగా ఉంచుతుంది, తద్వారా ఒక పేరుకు మద్దతు ఉందా అని క్లయింట్‌లు అడగవచ్చు, ఆ తర్వాత ప్యాకేజీలోని రన్‌టైమ్-నిర్దిష్ట ప్రవేశ బిందువు ద్వారా దాన్ని పరిష్కరించవచ్చు.

ముడి పబ్లిక్ కీలను మాత్రమే కాకుండా `.bso` పేర్లను కూడా అంగీకరించాల్సిన Bitsocial-అవగాహన గల క్లయింట్, కమాండ్-లైన్ సాధనం లేదా సేవను మీరు అనుసంధానిస్తున్నప్పుడు దీన్ని ఉపయోగించండి.
