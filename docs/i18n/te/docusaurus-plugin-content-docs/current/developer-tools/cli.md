# Bitsocial CLI

`bitsocial-cli` అనేది Bitsocial ప్రోటోకాల్ బ్యాకెండ్‌తో పరస్పర చర్య చేయడానికి ఉపయోగించే కమాండ్-లైన్ సాధనం. స్థానిక P2P డెమోన్‌ను నడపడానికి, కమ్యూనిటీలను సృష్టించి కాన్ఫిగర్ చేయడానికి, కంటెంట్‌ను ప్రచురించడానికి ఇది మిమ్మల్ని అనుమతిస్తుంది -- అన్నీ టెర్మినల్ నుండే.

ఇది భాగస్వామ్య Bitsocial ప్రోటోకాల్ క్లయింట్ పొరపై నిర్మించబడింది మరియు కమ్యూనిటీ సృష్టి, నోడ్ నిర్వహణ కోసం [5chan](/apps/5chan/) మరియు [Seedit](/apps/seedit/) దీన్ని ఉపయోగిస్తాయి.

## సంస్థాపన

Windows, macOS మరియు Linux కోసం ముందుగా నిర్మించిన బైనరీలు అందుబాటులో ఉన్నాయి. GitHub నుండి మీ ప్లాట్‌ఫారమ్ కోసం తాజా విడుదలను డౌన్‌లోడ్ చేయండి:

**[GitHub విడుదలల నుండి డౌన్‌లోడ్ చేయండి](https://github.com/bitsocialnet/bitsocial-cli/releases)**

డౌన్‌లోడ్ చేసిన తర్వాత, బైనరీని ఎక్జిక్యూటబుల్‌గా చేయండి (macOS/Linux):

```bash
chmod +x bitsocial
```

## డెమోన్‌ను నడపడం

CLI యొక్క అత్యంత సాధారణ ఉపయోగం Bitsocial నోడ్‌ను నడపడమే. డెమోన్ P2P నెట్‌వర్కింగ్ పొరను ప్రారంభిస్తుంది మరియు క్లయింట్‌లు కనెక్ట్ కాగలిగే స్థానిక APIని బహిర్గతం చేస్తుంది.

```bash
bitsocial daemon
```

మొదటిసారి ప్రారంభించినప్పుడు, డెమోన్ **WebUI**కి లింక్‌లను చూపిస్తుంది; ఇది మీ నోడ్, కమ్యూనిటీలు మరియు సెట్టింగ్‌లను నిర్వహించడానికి బ్రౌజర్ ఆధారిత గ్రాఫికల్ ఇంటర్‌ఫేస్. టెర్మినల్ ఆదేశాల కంటే GUIని మీరు ఇష్టపడితే ఇది ఉపయోగపడుతుంది.

## ముఖ్య చర్యలు

| చర్య                              | వివరణ                                                         |
| --------------------------------- | ------------------------------------------------------------- |
| డెమోన్‌ను ప్రారంభించడం            | Bitsocial P2P నోడ్‌ను ప్రారంభించండి                           |
| కమ్యూనిటీని సృష్టించడం            | కొత్త కమ్యూనిటీని సృష్టించండి                                 |
| కమ్యూనిటీని సవరించడం              | కమ్యూనిటీ సెట్టింగ్‌లను నవీకరించండి (శీర్షిక, వివరణ, నియమాలు) |
| స్థానిక కమ్యూనిటీలను జాబితా చేయడం | ఈ నోడ్‌లో హోస్ట్ చేసిన కమ్యూనిటీలను జాబితా చేయండి             |
| కమ్యూనిటీని ప్రారంభించడం          | ఒక నిర్దిష్ట కమ్యూనిటీకి సేవ అందించడం ప్రారంభించండి           |
| కమ్యూనిటీని ఆపడం                  | ఒక నిర్దిష్ట కమ్యూనిటీకి సేవ అందించడం ఆపండి                   |

మీరు ఇన్‌స్టాల్ చేసిన విడుదల బహిర్గతం చేసే ప్రస్తుత ఆదేశ పేర్లు మరియు ఫ్లాగ్‌లను చూడటానికి CLIని `--help`తో నడపండి:

```bash
bitsocial --help
bitsocial daemon --help
```

## సాధారణ వర్క్‌ఫ్లో

కొత్త కమ్యూనిటీని హోస్ట్ చేయడానికి ఒక సాధారణ సెటప్ ప్రవాహం:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

అక్కడి నుండి, ఒక కమ్యూనిటీని సృష్టించడానికి, కాన్ఫిగర్ చేయడానికి మరియు దానికి సేవ అందించడం మొదలుపెట్టడానికి మీరు ఇన్‌స్టాల్ చేసిన విడుదలలోని కమ్యూనిటీ-నిర్వహణ ఆదేశాలను ఉపయోగించండి. ప్రారంభించిన తర్వాత, కమ్యూనిటీ Bitsocial నెట్‌వర్క్‌లో ప్రత్యక్షంగా ఉంటుంది మరియు అనుకూల క్లయింట్‌ల నుండి దాన్ని యాక్సెస్ చేయవచ్చు.
