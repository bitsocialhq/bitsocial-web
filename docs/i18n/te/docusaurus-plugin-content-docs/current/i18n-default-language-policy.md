# i18n డిఫాల్ట్ భాషా విధానం

అనామక సందర్శకులకు భాష ఈ క్రమంలో నిర్ణయమవుతుంది:

1. `?lang=` క్వెరీ పారామీటర్
2. సేవ్ చేసిన భాషా ఎంపిక (బ్రౌజర్‌లో `localStorage`, SSR కోసం `i18nextLng` కుకీలో కూడా ప్రతిబింబిస్తుంది)
3. బ్రౌజర్/పరికర భాష, అది మనం మద్దతు ఇచ్చే లొకేల్‌లలో ఒకటి అయినప్పుడు
4. చివరి ప్రత్యామ్నాయంగా `en`

మద్దతు ఉన్న బ్రౌజర్/పరికర భాషను అధిగమించడానికి దేశం లేదా ప్రాంతం ఉపయోగించబడదు. ఉదాహరణకు, `de-DE` జర్మన్‌గా, `nl-NL` డచ్‌గా, `pt-PT` పోర్చుగీస్‌గా నిర్ణయమవుతాయి, ఎందుకంటే ఆ లొకేల్ కుటుంబాలకు మద్దతు ఉంది.

బ్రౌజర్/పరికర భాష ఏ మద్దతు ఉన్న లొకేల్‌తోనూ సరిపోలకపోతే, సందర్శకులకు ఆంగ్ల డిఫాల్ట్ అందుతుంది.
