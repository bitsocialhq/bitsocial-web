# Bitsocial CLI

`bitsocial-cli` — это консольный инструмент для работы с протокольным бэкендом Bitsocial. Он позволяет запустить локальный P2P-демон, создавать и настраивать сообщества, публиковать контент — и всё это прямо из терминала.

Он построен на общем клиентском слое протокола Bitsocial, и его же используют [5chan](/apps/5chan/) и [Seedit](/apps/seedit/) для создания сообществ и управления узлом.

## Установка

Готовые сборки есть для Windows, macOS и Linux. Скачайте последний релиз для своей платформы с GitHub:

**[Скачать из GitHub Releases](https://github.com/bitsocialnet/bitsocial-cli/releases)**

После загрузки сделайте файл исполняемым (macOS/Linux):

```bash
chmod +x bitsocial
```

## Запуск демона

Чаще всего CLI используют именно для запуска узла Bitsocial. Демон поднимает сетевой P2P-слой и открывает локальный API, к которому подключаются клиенты.

```bash
bitsocial daemon
```

При первом запуске демон выводит ссылки на **WebUI** — графический интерфейс в браузере для управления узлом, сообществами и настройками. Это удобно, если терминалу вы предпочитаете графический интерфейс.

## Основные действия

| Действие                      | Описание                                                     |
| ----------------------------- | ------------------------------------------------------------ |
| Запустить демон               | Запуск P2P-узла Bitsocial                                    |
| Создать сообщество            | Создание нового сообщества                                   |
| Изменить сообщество           | Обновление настроек сообщества (название, описание, правила) |
| Показать локальные сообщества | Список сообществ, размещённых на этом узле                   |
| Запустить сообщество          | Начать обслуживать конкретное сообщество                     |
| Остановить сообщество         | Прекратить обслуживать конкретное сообщество                 |

Запустите CLI с `--help`, чтобы увидеть актуальные имена команд и флаги в установленной у вас версии:

```bash
bitsocial --help
bitsocial daemon --help
```

## Типичный сценарий

Обычная последовательность действий при запуске нового сообщества:

```bash
# 1. Start the daemon
bitsocial daemon

# 2. In another terminal, inspect the available community-management commands
bitsocial --help
```

Дальше пользуйтесь командами управления сообществами из установленной версии, чтобы создать сообщество, настроить его и начать обслуживать. После запуска сообщество доступно в сети Bitsocial из любых совместимых клиентов.
