# Voucher Challenge

Voucher Challenge открывает публикацию контента только по уникальным кодам-ваучерам, которые раздаёт владелец сообщества. Вместо автоматической оценки доверие переносится на ручной поток приглашений: знакомые люди получают коды через канал, который контролирует владелец.

- **Исходный код и актуальный README:** [github.com/bitsocialnet/voucher-challenge](https://github.com/bitsocialnet/voucher-challenge#readme)
- **Пакет npm:** [`@bitsocial/voucher-challenge`](https://www.npmjs.com/package/@bitsocial/voucher-challenge)

## Установка

```bash
npm install @bitsocial/voucher-challenge
```

## Как это работает

1. Владелец сообщества создаёт один или несколько уникальных кодов-ваучеров.
2. Владелец раздаёт эти коды доверенным авторам через канал на своё усмотрение (личное сообщение, электронная почта, лично и так далее).
3. Когда автор пытается что-то опубликовать, система проверки запрашивает у него код-ваучер.
4. Код проверяется — если он подлинный и ещё не использовался, публикация принимается.

После погашения каждый код-ваучер привязан к конкретному автору, поэтому другие им воспользоваться не смогут.

## Когда её использовать

Voucher Challenge лучше всего подходит для:

- **Сообществ по приглашениям**, где членство ограничено намеренно.
- **Кураторских пространств**, где владелец лично проверяет каждого участника.
- **Среды с высоким уровнем доверия**, где автоматическая оценка спама не нужна или нежелательна.

Поскольку коды приходится раздавать вручную, этот подход не масштабируется на большие открытые сообщества. Для таких случаев стоит посмотреть на [Spam Blocker](./spam-blocker.md) или [EVM Contract Call Challenge](./evm-contract-call.md).
