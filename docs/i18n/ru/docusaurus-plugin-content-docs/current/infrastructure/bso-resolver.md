# BSO Resolver

BSO Resolver превращает доменные имена `.bso` в соответствующие им открытые ключи, читая TXT-записи Bitsocial. Это тот самый пакет-резолвер, который инструменты Bitsocial используют, когда понятное человеку имя `.bso` нужно превратить в ключевой материал, с которым работает одноранговый стек.

- **Исходный код и актуальный README:** [github.com/bitsocialnet/bso-resolver](https://github.com/bitsocialnet/bso-resolver#readme)
- **Пакет npm:** [`@bitsocial/bso-resolver`](https://www.npmjs.com/package/@bitsocial/bso-resolver)

## Установка

```bash
npm install @bitsocial/bso-resolver
```

## Где он нужен

Имена Bitsocial задуманы как понятные человеку точки входа к сообществам и авторам. Резолвер держит этот слой именования отдельно от кода приложения: клиент может сначала спросить, поддерживается ли имя, а затем разрешить его через точку входа пакета для нужной среды выполнения.

Он пригодится, если вы собираете клиент, консольный инструмент или сервис с поддержкой Bitsocial, который должен принимать имена `.bso`, а не только сырые открытые ключи.
