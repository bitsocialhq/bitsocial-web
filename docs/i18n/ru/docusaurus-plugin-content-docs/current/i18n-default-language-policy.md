# Политика языка по умолчанию в i18n

Для анонимных посетителей язык определяется в следующем порядке:

1. Параметр запроса `?lang=`
2. Сохранённый выбор в переключателе языка (`localStorage` в браузере, дублируется в cookie `i18nextLng` для SSR)
3. Язык браузера или устройства, если он входит в число поддерживаемых локалей
4. Откат на `en`

Страна или регион не используются для переопределения поддерживаемого языка браузера или устройства. Например, `de-DE` разрешается в немецкий, `nl-NL` — в нидерландский, а `pt-PT` — в португальский, потому что эти семейства локалей поддерживаются.

Если ни один язык браузера или устройства не совпадает с поддерживаемой локалью, посетитель получает английскую версию по умолчанию.
