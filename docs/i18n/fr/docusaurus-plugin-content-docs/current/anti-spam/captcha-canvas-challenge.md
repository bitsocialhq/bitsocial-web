# Défi Captcha Canvas

Captcha Canvas Challenge est un package de captcha par image autonome destiné aux communautés Bitsocial. Il dessine un texte aléatoire sur un canvas et permet à une communauté de demander aux auteurs de résoudre l'image avant qu'une publication soit acceptée.

- **Code source et README à jour :** [github.com/bitsocialnet/captcha-canvas-challenge](https://github.com/bitsocialnet/captcha-canvas-challenge#readme)
- **Package npm :** [`@bitsocial/captcha-canvas-challenge`](https://www.npmjs.com/package/@bitsocial/captcha-canvas-challenge)

## Installation

```bash
npm install @bitsocial/captcha-canvas-challenge
```

## Où il s'inscrit

Les défis captcha sont utiles lorsqu'une communauté veut une barrière interactive simple pour résister au spam à faible enjeu. Ce package est volontairement restreint : il fournit l'implémentation du défi, tandis que la communauté ou le nœud Bitsocial décide quand et comment le présenter.

Pour une protection plus forte, associez-le à des systèmes de modération ou d'évaluation du risque plus larges, plutôt que de traiter un captcha comme une stratégie anti-spam complète.
