# Palakihin ang mga Ekonomiya ng Bitsocial

Ang Yugto 4 ay tungkol sa paglaki ng ecosystem nang sapat upang walang iisang kumpanya, RPC,
hosting provider, o client ang maging bagong may-ari ng platform.

Kayang buuin ng Bitsocial Forge ang unang pampublikong RPC at ang mga unang malalaking serbisyo,
ngunit hindi iyon dapat ang huling kalagayan. Mas malusog ang network kung maraming negosyo, team,
anonymous na operator, entidad ng komunidad, at independiyenteng developer ang makakabuo ng
kapaki-pakinabang na imprastraktura sa ibabaw ng Bitsocial.

## Ano ang kailangang lumaki

Higit pa sa mga app ang kailangan ng ecosystem:

- magkakatunggaling pampublikong RPC
- mga serbisyo sa pag-host ng media
- mga serbisyo sa pagtuklas at pag-index
- mga serbisyo sa moderation
- mga provider ng feed algorithm
- pag-host ng profile node
- analytics at observability
- mga kasangkapan para sa developer
- mga grant at channel ng pagpopondo

Dapat mapapalitan ang bawat serbisyo. Maaaring maging matagumpay ang isang kapaki-pakinabang na
provider, ngunit dapat pa ring may ibang mapupuntahan ang mga user at app.

## Pagpopondo bilang desentralisasyon

Dapat itulak ng pagpopondo ang network patungo sa mas maraming independiyenteng operator, hindi
patungo sa iisang permanenteng sentro.

Ibig sabihin nito ay pagpopondo sa mga developer na bumubuo ng mga client, imprastraktura,
kasangkapan sa moderation, kasangkapan sa pag-index, karanasan sa mobile, serbisyo sa media, at
magkakatunggaling RPC. Ibig sabihin din nito ay pag-iwan ng puwang para sa mga kumpanya, grupo ng
komunidad, anonymous na operator, at nag-iisang developer upang makahanap ng napapanatiling negosyo
sa loob ng network.

## Bakit mahalaga ang mga ekonomiya

Magastos panatilihin ang imprastrakturang panlipunan. Kung iisang organisasyon lamang ang
nagbabayad para sa RPC, hosting, pagtuklas, at pagbuo, mananatiling marupok ang network kahit
peer-to-peer ang protocol.

Ang mas matibay na bersyon ay isang merkado ng mga serbisyo sa paligid ng protocol:

- naglalaban ang mga client para sa mga user
- naglalaban ang mga RPC sa pagiging maaasahan at sa modelo ng tiwala
- naglalaban ang mga media host sa presyo at patakaran
- naglalaban ang mga serbisyo sa pagtuklas sa kaugnayan ng resulta
- naglalaban ang mga developer para sa mga grant, kita, at reputasyon

Dapat gawing mas mahirap agawin ng mga ekonomiya ng Bitsocial ang protocol sa pamamagitan ng
paggawang mapopondohan ang kapaki-pakinabang na trabaho sa maraming independiyenteng aktor.
